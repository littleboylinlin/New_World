# 本地任务管理工作区（开发中，尚未发行）

本次基于已发布 v0.18.1，保持应用版本号与发布配置不变。任务入口在首页「任务管理」或 `#/tasks`。无需 Todoist、账号、网络服务或外部日历。任务是独立本地记录；完成任务不会修改灵感的「已使用」状态，也不改写小说正文。

## 实际功能与操作

- 收件箱、今日（计划在本机今天及以前，或截止期限已逾期）、即将到来、全部、已完成、任务回收站；按标题、描述、备注、评论和作品快照名称搜索。
- 快速添加、完整表单编辑、完成/取消完成、软删除/按批次恢复、复制、P1–P4、标签、独立备注和多段描述。多层子任务支持展开、收起、拖动及按钮排序；父子任务保持同一项目/分区及作品归属。移动保留 ID 并原子移动整棵子树。
- 批量选择、移动项目、优先级、计划日期、完成与删除。清空批量日期同时取消具体时间、重复规则和提醒；独立截止期限不变。
- 项目/子项目、文字或表情图标、颜色、收藏、排序、归档、删除恢复；项目内分区，统一标签管理及标签收藏。删除分区只取消该分区归类；删除标签隐藏标签但保留引用，可恢复。副本导入允许同名项目/标签存在，身份按 UUID 区分，绝不靠名称合并或覆盖数据。
- 列表、分区看板、月/周日历、属性表格共享同一份数据。看板拖动更改项目/分区；日历拖动更改计划日期，独立截止期限不变。表格通过任务标题进入同一编辑器。项目保存视图、日历范围及排序；全局视图保存在本机设置。较大列表按 200 条分批载入，不截断存储或导出。
- 组合过滤器可保存、编辑、删除、收藏，支持嵌套「全部/任一」组；字段为文字、项目、标签、优先级、状态、计划日期、截止期限。使用类型化条件，不执行查询代码。
- 任务详情可管理评论和附件。评论可编辑、删除、恢复；附件仅下载，不执行或内嵌预览。支持 UTF-8 TXT/MD/CSV、PDF、DOCX、PNG/JPEG/GIF/WebP，校验类型、签名、大小和 SHA-256。拒绝脚本、可执行文件、HTML、SVG 等不支持资源。
- 从任务保存多层模板，保留未删除子任务、标签、日程、作品关联、评论和附件；不复制完成历史，清空项目/分区。使用时生成新的任务、评论与附件身份；保留模板日期，可随后调整。模板是全局可复用资料，不随单部小说导出。
- 完成历史按实际事件记录。统计按本机日、周（星期一开始）、月分组，排除已撤销的完成；父子任务分别计数，不补造历史、不提供积分。
- 非输入状态快捷键：`N` 聚焦快速添加，`/` 搜索，`Esc` 清除选择，`Ctrl/⌘+Z` 撤销，`Alt+Enter` 完成选中任务。输入框和小说编辑器保留自己的快捷键。

## 时间与重复

计划日期为 `YYYY-MM-DD`，具体时间为 `HH:mm`；有时间时必须带 IANA 时区，可在夏令时重复时刻中明确选择较早或较晚的一次。工作区跨日自动刷新（前台每 30 秒检查，恢复焦点时也刷新），不改写计划日期。日期型任务不跨时区换算；时间型任务按真实时刻分配到本机的今日/未来视图。不猜测不存在的夏令时时刻，验证失败时不写入。截止期限独立于计划日期；持续时间以分钟保存。

重复规则：每天、每周、每月、每年、每隔 N 个周期、指定星期几、每月一个或多个日期，含结束当日的结束日期。月末缩短不改变原始锚点（1 月 31 日 → 2 月末 → 3 月 31 日）；闰年同理。完成逾期重复任务跳到下一次未来日期，不伪造错过的完成记录。取消重复保留已有历史。

重复父任务管理普通子任务整棵树，子任务不能再有独立重复规则；会明确拒绝这种设置。完成保留任务 ID，记录本次事件，将子任务计划日期按周期平移、重新打开；独立截止期限不变，已删除子任务保持删除。历史记录保存恢复该周期所需的最小日期/完成状态及修订号。恢复最新完成时检查后续修改；有修改、缺失任务或被移动的成员时拒绝覆盖，可手动调整。其他会话/操作改变数据后，旧的会话撤销也会拒绝覆盖。

双语识别支持「明天下午三点」「每周一」「下个月 5 号」「每隔 N 天/周」、today/tomorrow/day after tomorrow、every Monday、every N days/weeks、daily/weekly/monthly/yearly、常见 am/pm/24 小时时间等。按表单所选时区生成日历建议，必须点击采用并保存；不剥离标题。冲突日期、多个时间、歧义的中文午夜、非法时间等不猜测，保留原文字供手动填写。这是有界的常见语句识别，不是完整自然语言理解。

## 提醒能力边界

用户须在「本地提醒与快捷键」启用本机提醒，并授权通知。应用运行且渲染进程活跃时检查；后台、最小化或系统节流可能延迟，恢复时补查最近 7 天。一次最多提交 3 个通知请求；多个窗口通过事务争用带租约的去重记录。归档任务项目不提醒。

完全退出、关闭浏览器、设备关机后不通知；没有 OS 级定时服务、外部服务器、服务工作线程或外部日历同步。系统仍可因通知权限、勿扰模式等抑制展示，启用不等于已送达。自动化使用 Notification API 替身验证权限、启用与去重，不冒充真实系统通知展示验收。

## 创作联动与归属

作品详情可创建任务、查看该作品全部任务；编辑器可从当前版本/章节和选区创建任务，不改变正文。任务详情可跳回真实作品/章节，选区仅在正文指纹及位置仍匹配时恢复；正文变化时保留原引用并提示重新定位。版本或章节缺失明确提示，不误跳其他内容。

灵感菜单可手动转为任务；原灵感、已使用状态及其历史完全保留。任务初始文字取自灵感，确认保存后成为独立记录。

一棵任务树的作品归属必须一致。修改父任务归属会同步子树并清除不兼容的版本/章节/位置关联（界面有说明，当前会话可撤销）；子任务要换作品须先移出。单独作品归档/删除不删除任务；归档反馈和删除确认均有说明。缺失作品显示原名称快照并允许重新关联，恢复同 ID 作品可恢复链接。单独导入任务 JSON 的外部作品链接全部标记为待确认，防止相同 UUID 误绑定到本机作品。

`.newworld` **Schema 3** 只导出明确确认关联当前作品的任务（含完成/删除记录），所需项目及祖先、被引用分区/标签、完成记录及附件；不导出个人任务、其他作品任务、未确认的外部链接、全局过滤器/模板或本机设置。历史周期成员后来移出作品时只保留历史最小状态和显式断开身份，不带走该成员当前个人内容，也不补造任务。详见 [工程规范](newworld-format.md)。

## 数据、升级与原子性

IndexedDB v8 → **v9** 只新增九个独立对象仓库：`tasks, taskProjects, taskSections, taskLabels, taskCompletions, taskSettings, taskFilters, taskTemplates, taskAttachments`，各表主键为 `id`。不重写现有作品、metadata、章节、原文、图片、批注、灵感、历史或书库索引。旧 v0.18.1 不能直接打开 v9 数据库，回退应使用升级前备份。

每次图修改读取同一快照，在单个 strict 写事务内检查类型、闭合字段、层级/循环、引用、重复身份、日期和上限，再逐行写入；异常整体回滚。任务/项目修订号防止覆盖过期表单，标签和分区也检查修订号。跨窗口通过 BroadcastChannel 更新。导入只追加；不覆盖或清空书库。

软删除用批次 UUID，项目删除包括子项目/分区/任务；恢复只还原同一批次，早先独立删除的数据仍保持删除。已删除成员的历史和附件一直保留。会话撤销保留最近一次写入前快照，应用重启后仍可从任务回收站恢复删除项。

限制：最多 30000 个顶层记录，32 层层级，任务结构 JSON 32 MiB、最多 100 万 JSON 节点、64 层嵌套（资源标记编码另留有界开销），数量/复杂度检查在异步资源解码前执行；标题/名称 500，描述/备注/评论 20000 字符；每任务最多 1000 评论、100 标签；过滤器最多 100 条条件、8 层组。模板每份最多 1000 任务；附件每个 16 MiB、含模板附件累计 64 MiB。时间字段均有类型、有效日历/时区和安全整数约束。未知结构字段报错，不借作品 metadata 绕过任务规范。

全库 ZIP 备份独立升级为格式 **2**，包含九个任务表和按字节保存的附件，也可加密；恢复使用同一原子事务。读格式 1 仍有效，旧备份无任务数据时保留现有任务。已发布旧软件拒绝格式 2。全库备份和单部工程导入是不同入口与机制。

## 独立任务 JSON 格式 1

开放 UTF-8 JSON，文件上限 128 MiB。必填根字段：

| 字段 | 约束 |
| --- | --- |
| `format` | `new-world-tasks` |
| `schemaVersion` | 整数 `1`，独立于应用、数据库和工程 Schema |
| `appVersion` / `createdAt` | 来源应用字符串/导出 Unix 毫秒 |
| `detached` | 周期历史引用但无任务行的 UUID，排序、唯一，读取后重新计算比对 |
| `data` | 九个任务表数组，`taskSettings` 必须为 `[]` |
| `resources` | `{id,type,bytes,sha256,base64}[]`，全清单，无遗漏/额外/重复资源 |

二进制字段以 `{ "$taskResource": "资源 id" }` 表示。`sha256` 为原始字节 SHA-256；资源 id 为 `SHA-256(UTF-8(sha256 + "\n" + MIME))`，类型参与资源身份；base64 必须规范且与字节数一致。读取器校验资源与全部记录，再显示数量、冲突及保留 ID/副本/跳过选项。副本重映射全部任务域身份、历史、子任务、评论、附件、模板及过滤器引用，文字和哈希不做替换。导出后通过相同读取器自校验。格式 1 只接受公开定义字段，不支持的未来格式明确拒绝。

## 自动化与验收材料

分阶段提交：任务核心 → 时间与共享视图 → 创作联动、资源和工程完整性。测试入口：

- `tests/unit/tasks-*.mjs`：闭合模型、树/引用、日期、重复、月末/闰年/DST、双语识别及嵌套过滤。
- `tasks-core.spec.mjs`：真实 CRUD、多层任务、排序拖动、持久化、批量操作、项目/标签、并发及事务中断。
- `tasks-time.spec.mjs`：确认日期建议、完成周期与恢复、非法日期回滚、看板/日历拖动、多视图与过滤器、提醒替身。
- `tasks-integration.spec.mjs` / `tasks-projects.spec.mjs`：真实任务 JSON 和 Schema 3 跨干净书库往返，隐私隔离、原字节、ID 冲突、失败回滚、Schema 2 读取、章节联动、灵感不变、模板/统计及删除作品保留任务。
- `tasks-integrity.spec.mjs`：升级中断原子回滚后重试、完整 v8 数据保留、周期树恢复和后续修改保护、分页/连续输入及快捷键。
- `tasks-backup.spec.mjs`：旧备份保留任务，新备份整体替换，附件字节及损坏拒绝。现有工程测试继续读取 Schema 1，并验证升级、批注和历史等。
- Windows/macOS 共用 `tests/desktop/project-flow.mjs`：安装包中创建章节任务、个人任务隔离、Schema 3 原生导出、文件关联及重启持久化；平台 CI 执行结果以对应运行链接为准。
