# 本地任务管理工作区

开发阶段一：独立任务模型与核心管理（尚未发布，应用版本仍为 v0.18.1）。入口位于首页「任务管理」，也可访问 `#/tasks`。任务完成与灵感的已使用状态没有关联。

## 数据与恢复

IndexedDB 从 v8 升至 v9，新增 tasks、taskProjects、taskSections、taskLabels、taskCompletions、taskSettings 独立对象仓库，并预建 taskFilters、taskTemplates、taskAttachments 三个空表供后续阶段使用；第一阶段拒绝这些表中的非空记录，避免把尚未支持的数据当作成功导入。升级只创建新表，不重写作品、富文本、图片、批注、灵感或历史。旧 v0.18.1 不能直接打开 v9 数据库；保留升级前备份以备回退。

任务、子任务和项目使用稳定 UUID，父子关系为显式 ID 引用；有序值独立于标题，移动任务会原子移动整棵子树。最多 32 层，总记录最多 30000，任务 JSON 总量最多 32 MiB，标题最多 500、描述/备注各 20000 字符。每次写入均验证类型、引用、循环、层级、日期和数量，在单个 strict 事务中执行；表单使用修订号防止覆盖过期任务。跨窗口通过 BroadcastChannel 刷新。

任务删除保留记录与完成历史，整棵子树共享一个删除批次；恢复按批次执行。项目删除连同子项目、分区与任务移入任务回收站，可整体恢复。分区删除仅移除分区归类，任务留在原项目。标签保留稳定引用，删除后隐藏，恢复标签后原归类仍在。项目归档不删除任务，归档项目的任务不进入今日等普通视图，可从归档项目直接查看。

完成父任务会完成其未完成子任务并逐条记录实际完成事件。取消完成不会删除完成历史。撤销针对当前会话最近的一次任务写入；如果之后其他窗口或其他操作修改了任务数据，将拒绝撤销，避免覆盖新数据。重新启动后仍可用回收站恢复删除项。

全库 ZIP 备份升级为版本 2，包含独立任务数据；读取器继续读取版本 1。恢复旧备份时保留现有任务，新备份恢复任务与作品使用同一原子事务。旧版软件明确拒绝版本 2 备份。当前 `.newworld` Schema 2 仍不包含任务，任务尚无作品关联；第三阶段将正式新增工程结构，不能将任务塞入 metadata 扩展字段。

## 阶段一验收

提供收件箱、今日（含逾期）、未来计划、全部任务、已完成与回收站。支持快速添加、表单编辑、描述/备注、计划日期、P1–P4、标签、层级子任务、展开收起、拖动及按钮排序、复制、批量选择/移动/优先级/日期/完成/删除。项目支持子项目、颜色、文字或表情图标、收藏、排序、归档与删除恢复；分区和标签可独立管理。

`tests/tasks-core.spec.mjs` 覆盖真实 UI 持久化、三层任务、完成与恢复、复制、拖动、批量移动、项目/分区/标签、日期搜索、并发冲突与事务中断。纯模型边界由 `tests/unit/tasks-unit.mjs` 验证。旧数据库升级、作品工程往返及原书库功能继续由现有回归测试验证。
