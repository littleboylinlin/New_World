## 归档与备份

- 新增归档：书库中的作品可以归档，归档后不在书库中显示，内容保持不变，可撤销。首页的「归档」和书库列表旁的「查看归档」可以打开、编辑、取消归档或删除归档作品。
- 新增「设置 → 备份」：把两个书库、全部编辑稿、原文件和回收站备份为一个 `.zip` 文件，可选择用密码加密（AES-256）。
- 桌面版支持自动备份（每天、每周或关闭），默认保存到「文稿」下的 `New World Backups`，也可以自选文件夹；自动备份保留最近 10 份。
- 可以从备份恢复整个书库，加密备份需要输入密码；桌面版恢复前会先自动备份当前书库。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Archive and backups

- New archive: works can be archived off the shelves and keep everything; archiving can be undone. "Archive" on the home page and "View archive" beside each library list open, edit, unarchive or delete archived works.
- New "Settings → Backups": back up both libraries, every edition, the original files and the trash into one `.zip` file, optionally encrypted with a password (AES-256).
- The desktop app backs up automatically (daily, weekly or off), by default to `New World Backups` in Documents or to a folder of your choice, keeping the newest 10 automatic backups.
- Restore the whole library from a backup, entering the password for an encrypted one; the desktop app backs up the current library first.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
