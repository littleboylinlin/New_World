## 阅读批注系统

- **选中文字即可添加批注**：原创库和续写／仿写库的编辑稿阅读模式，以及文字原件预览，均可通过选区旁的「添加批注」输入多行内容（最多 10000 字符）。支持保存、取消、查看、编辑和删除，保存后立即显示，关闭并重新打开作品后继续保留。
- **两种展示形式共用批注数据**：可按条选择行间批注或文字颜色标记，并随时切换。行间批注跟随选区结束所在段落或块展示，可展开、收起；文字标记提供五种预设色和自定义颜色。重叠范围保留全部批注，并在预览卡片中分别列出。
- **悬停预览与点击固定**：指向标记文字可预览批注，移动到卡片后可继续阅读；点击文字或卡片可固定，移开鼠标后仍保持展开。点击其他位置、其他标记、关闭按钮或按 Escape 收起。弹层会根据窗口空间调整位置，选区工具栏会在取消选区、滚动、切换章节、切换模式或打开查找时清理。
- **准确定位并保护原文**：批注使用稳定 ID、章节或原件标识、精确位置、原文摘录和 SHA-256 校验，避免把重复文字关联到错误位置。批注作为附加数据保存，不写入正文；并发保存会检查版本冲突，正文保存、原文件下载及现有正文导出流程保持原有行为。
- **兼容现有书库与恢复流程**：旧记录缺少批注字段时按空集合读取，无需重写正文或升级数据库版本。批注随所属记录进入回收站，并随整库备份保存和恢复。已通过选区、跨段落、重叠、颜色、窄窗口、悬停固定、章节切换、并发冲突、导出与备份的自动化回归，以及 Windows 安装版重启持久化测试。

### 已知限制

- 支持 TXT、Markdown 源码、HTML 纯文本、RTF、DOCX、ODT 和 EPUB 文字预览。PDF 当前为画布预览，暂不支持文字批注；仅下载的格式和图片本身也不支持文字选区批注。
- 锚点采用整章文档级校验。章节内容或格式发生变化，或原件当前解码文字改变后，旧锚点会失效；批注内容仍保留并显示提示，不会静默改标到其他文字。恢复完全一致的正文后可恢复标记。当前版本暂不支持自动重新定位或手动重新锚定。
- 正文导出不包含批注，当前版本暂不提供独立批注导出格式。整库备份仍会保留批注数据。

详细说明见 [阅读批注](https://github.com/littleboylinlin/New_World/blob/v0.17.0/docs/reading-annotations.md)。提供 Windows x64、Mac Apple Silicon（arm64）和 Intel（x64）安装包，以及简体中文、英语语言包。使用同页的 `SHA256SUMS.txt` 校验下载文件。

## Reading Annotations

- **Create annotations from selected text**: Select text in manuscript reading mode in either library, or in a text source preview, and choose “Add annotation” next to the selection. Notes support multiple lines and up to 10,000 characters. Create, cancel, view, edit, and delete notes; saved annotations appear immediately and persist after reopening the work.
- **Two display styles share the same data**: Choose inline cards or text highlights for each annotation and switch at any time. Inline cards follow the block where the selection ends and can be expanded or collapsed. Highlights offer five preset colors and a custom color picker. Overlapping ranges retain every annotation and list them separately in the preview.
- **Hover to preview, click to pin**: Hover over highlighted text and move into the card to keep reading. Click the text or card to pin it open. Click elsewhere, another highlight, the close button, or press Escape to dismiss it. Popups adjust to the available window space; selection controls clear when the selection is dismissed, the page scrolls, the chapter or mode changes, or Find opens.
- **Precise anchors preserve source text**: Stable IDs, chapter or source identity, exact positions, quoted text, and SHA-256 validation prevent repeated passages from being misidentified. Annotations are stored as metadata outside the document tree. Concurrent saves check versions, while source saves, original-file downloads, and existing document exports keep their established behavior.
- **Compatible storage and recovery**: Existing records without annotation fields are read as empty collections, without rewriting source text or changing the database version. Annotations travel with their owners through Trash and full-library backups. Automated coverage includes selections, cross-paragraph and overlapping ranges, colors, narrow windows, hover and pin behavior, chapter switching, concurrent saves, exports, backups, and Windows persistence across app restarts.

### Known Limitations

- Text previews support TXT, Markdown source, HTML plain text, RTF, DOCX, ODT, and EPUB. PDF previews currently use a canvas and do not support text annotations. Download-only formats and images themselves do not provide text selections for annotations.
- Anchors validate the entire chapter document. Changes to chapter content or formatting, or to the currently decoded source text, invalidate existing anchors. Notes remain available with a notice and are never silently reassigned to different text. Restoring an identical source document restores valid highlights. Automatic repositioning and manual re-anchoring are currently unsupported.
- Document exports exclude annotations. A separate annotation export format is currently unavailable; full-library backups still preserve annotation data.
