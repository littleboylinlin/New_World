## v0.21.0 更新内容

- **桌面应用内更新**　检查更新时优先读取 `dl.writenewworld.com` 镜像，镜像不可用时查询 GitHub。下载安装包时两个来源同时起跑，优先使用先传到 1 MiB 的来源。若该来源下载或校验失败，会尝试另一来源。安装前核对文件大小和 SHA-256。
- **平滑光标**　连续输入时，光标最多落后约一个字符宽度。长按产生重复输入时，光标直接定位。输入和换行时，编辑器会自动滚动，尽量在光标下方留出两行空间。打字机模式仍将当前行保持在编辑区中央附近。
- **页面切换**　从首页进入作品时，上一页的视图和动画及时清理。返回首页时，书库标题直接显示。开启「减少动态效果」时，页面直接切换。
- **回收站提示**　入口用黄点提示自上次查看以来新移入的条目。打开回收站后黄点消失，查看时间保存在本地。
- **阅读与写作版式**　可在作品的写作界面直接调整字号、行距、段落间距、首行缩进和正文宽度。设置首页也有入口，可跳到外观分类顶部的版式设置。
- **全局快捷键自定义**　桌面版可以录制、关闭或恢复灵感速记的快捷键，默认仍为 Ctrl + Alt + N。组合须包含 Ctrl、Alt、Cmd 或 Win/Super 中的至少一个。只用 Shift 时，仅允许搭配 F1–F24。注册失败时会提示并保留原设置。

### 兼容性

本版将书库数据库升至 v10，为回收条目的删除时间新增索引。工程仍使用 Schema 3，全库备份仍使用格式 2。若需回退到旧版，请在升级前保留一份全库备份。

## What's New in v0.21.0

- **In-app desktop updates**　The app checks the `dl.writenewworld.com` mirror first and falls back to GitHub if the mirror is unavailable. It starts installer downloads from both sources and continues with the one that delivers the first 1 MiB. If that source fails to download or verify, the app tries the other source. It checks the file size and SHA-256 before installation.
- **Smooth caret**　During fast typing, the caret stays within about one character width of the insertion point. It moves immediately on key repeats. The editor scrolls as you type and wrap lines, keeping two lines of space below the caret where possible. Typewriter mode still keeps the current line near the center of the editor.
- **Page transitions**　Opening a work from the home page clears the previous view and any lingering animation. The library heading appears immediately when you return home. With Reduce Motion enabled, pages switch immediately.
- **Trash indicator**　A yellow dot marks items moved to Trash since your last visit. The dot clears when you open Trash, and the app remembers your last visit on the device.
- **Reading and writing layout**　Use the Layout button in a work's editor to adjust font size, line spacing, paragraph spacing, first-line indentation, and text width. The main Settings page also links to the layout controls at the top of Appearance.
- **Custom global shortcut**　On desktop, you can record, disable, or restore the Quick Capture shortcut. The default remains Ctrl + Alt + N. A shortcut must include Ctrl, Alt, Command, or Win/Super. If Shift is the only modifier, it may be paired with F1–F24. If registration fails, the app shows an error and keeps your previous shortcut.

### Compatibility

This release upgrades the library database to v10 and adds an index for the time items were moved to Trash. Projects still use Schema 3, and full-library backups still use format 2. Keep a full-library backup from before the upgrade if you may need to return to an earlier version.
