## 升级前备份 / Back up before upgrading

**请先在 v0.18.1 中创建全库备份并保留文件，再安装 v0.19.0。** 本版将 IndexedDB **v8 升至 v9**、`.newworld` 写入格式从 **Schema 2 升至 Schema 3**、全库备份从**格式 1 升至格式 2**。v0.18.1 无法直接打开升级后的数据库、导入 Schema 3 或恢复格式 2；回退须使用升级前的格式 1 备份，不能直接复用升级后的书库。

**Create and keep a full-library backup in v0.18.1 before installing v0.19.0.** This release upgrades IndexedDB **v8 to v9**, `.newworld` output from **Schema 2 to Schema 3**, and full-library backups from **format 1 to format 2**. v0.18.1 cannot directly open the upgraded database, import Schema 3 or restore format 2. Rolling back requires a pre-upgrade format 1 backup; the upgraded library cannot be reused directly.

## 本地任务工作区

- **独立任务管理**：从首页「任务管理」进入收件箱、今日、即将到来、全部、已完成和任务回收站。支持快速添加、多层子任务、项目/分区、标签、P1–P4 优先级、搜索、批量操作、拖动排序、复制、删除与恢复。
- **共享视图和日程**：列表、看板、月/周日历和属性表格共用同一份数据；可保存嵌套组合过滤器。计划日期、具体时间、IANA 时区、独立截止期限与持续时间分别管理；支持每天/每周/每月/每年及间隔重复、指定星期/月日和结束日期。中英文日期建议必须手动采用后保存，不删除原标题。
- **评论、附件、模板与统计**：任务详情管理评论及受类型、大小和 SHA-256 校验的附件；附件仅下载，不执行或内嵌预览。多层模板可复用任务、评论和附件；完成统计按本机日、周、月计算，排除撤销事件。完成历史按实际事件时间排序；同一时刻使用已有周期修订号，无法可靠定序的旧记录保留历史并拒绝自动恢复。
- **创作联动**：作品详情和编辑器可创建作品/章节/选区任务，任务可跳回原位置；正文变化后不猜测位置。灵感可手动转为独立任务，原灵感、使用状态和历史保留。删除作品不会删除独立任务，缺失链接会提示重新关联。
- **任务交换与工程迁移**：提供独立任务 JSON 格式 1，支持预览、冲突检查、保留身份/副本/跳过和原子导入。Schema 3 工程只带明确归属当前作品的任务及必要项目、分区、标签、完成历史和附件；排除个人任务、其他作品、未确认链接、全局模板/过滤器和本机设置。全库备份格式 2 则包含全部九个任务表与附件原字节。

### 兼容性与限制

- v0.19.0 **读取 Schema 1/2/3，始终写入 Schema 3**；旧工程不补造作品信息或任务，再导出时使用新格式。已发布 Schema 1/2 示例不改写。现有作品信息、原文件、章节、批注、灵感及历史继续保留。
- IndexedDB v9 只增加九个任务对象仓库，不批量重写现有小说记录。升级中断整体回滚；任务修改及导入在校验后通过单个事务提交，冲突或失败不覆盖已有数据。
- 全库备份**读取格式 1/2，写入格式 2**。恢复格式 1 时保留现有任务；恢复格式 2 时替换全部任务表（含任务视图与提醒设置）及附件。单部 `.newworld` 工程不是全库备份，导入后的编辑也不会自动写回来源文件，须重新导出。
- **仅本地提醒，没有 Todoist 云端同步或账号系统。** 须手动启用并授权通知；仅在应用运行且渲染活跃时检查，后台、最小化或系统节流可能延迟。完全退出、浏览器关闭或设备关机后无通知，没有 OS 级定时服务；系统权限或勿扰模式仍可能阻止展示。自动化使用通知替身验证逻辑，未将其视为真实系统通知展示验收。
- 重复父任务管理普通子任务整棵树，子任务不支持独立重复规则。恢复最新周期时如检测到后续修改、缺失或移动成员，会拒绝覆盖。容量限制为最多 30000 条顶层记录、32 层任务层级、每个附件 16 MiB、含模板附件累计 64 MiB；其他边界见[任务文档](https://github.com/littleboylinlin/New_World/blob/v0.19.0/docs/tasks.md)与[工程规范](https://github.com/littleboylinlin/New_World/blob/v0.19.0/docs/newworld-format.md)。

## Local Task Workspace

- **Independent task management**: Open “Task management” from Home for Inbox, Today, Upcoming, All, Completed and task trash. Includes quick entry, nested subtasks, projects/sections, labels, P1–P4 priorities, search, bulk actions, drag ordering, duplication, deletion and recovery.
- **Shared views and scheduling**: List, board, month/week calendar and property table use the same data; nested filters can be saved. Plan dates, specific times, IANA zones, independent deadlines and durations remain distinct. Recurrence supports days/weeks/months/years, intervals, selected weekdays/month days and inclusive end dates. Chinese/English date suggestions require explicit adoption and saving, retaining the original title.
- **Comments, attachments, templates and statistics**: Manage comments and attachments checked by type, size and SHA-256. Attachments are download-only, without execution or embedded previews. Nested templates reuse tasks, comments and attachments. Statistics group actual completion events by local day, week and month, excluding reversals. Completion history follows event time and existing cycle revisions for timestamp ties; ambiguous old history is retained and automatic recovery refused.
- **Writing integration**: Create work/chapter/selection-linked tasks from work details or the editor and navigate back. Changed text does not trigger guessed positions. Manually convert an idea into an independent task while preserving the idea, its used state and history. Deleting a work leaves tasks intact; missing links can be reassociated.
- **Task transfer and project migration**: Independent task JSON format 1 provides preview, conflict checks, retained IDs/copies/skipping and atomic imports. Schema 3 projects include only confirmed tasks belonging to that work, plus required projects, sections, labels, completion history and attachments. Personal tasks, unrelated works, unconfirmed links, global templates/filters and device preferences are excluded. Full-library backup format 2 includes all nine task stores and original attachment bytes.

### Compatibility and Limitations

- v0.19.0 **reads Schema 1/2/3 and always writes Schema 3**. Importing older projects invents no metadata or tasks; exporting again uses the new format. Published Schema 1/2 samples stay unchanged. Existing work information, sources, chapters, annotations, ideas and history remain available.
- IndexedDB v9 only adds nine task stores without rewriting existing novel records. Interrupted upgrades roll back; task changes and imports commit in a single validated transaction, without overwriting data on conflicts or failures.
- Full-library backups **read formats 1/2 and write format 2**. Restoring format 1 keeps existing tasks; format 2 replaces all task stores (including task view and reminder settings) and attachments. A `.newworld` project is not a full-library backup. Imported edits are not written back automatically; export again to update the source file.
- **Local reminders only; no Todoist cloud sync or account system.** Enable reminders and grant notification permission first. Checks run only while the app is running with an active renderer. Background operation, minimization or system throttling may delay them. Fully exiting, closing the browser or shutting down stops notifications; there is no OS scheduler. Permissions and Do Not Disturb may suppress display. Automated notification substitutes verify logic, not actual OS notification display.
- A recurring parent manages its ordinary subtree; children cannot have separate recurrence rules. Recovering the latest cycle refuses to overwrite later edits or missing/moved members. Limits include 30000 top-level records, 32 task levels, 16 MiB per attachment and 64 MiB total including template attachments. See the [task guide](https://github.com/littleboylinlin/New_World/blob/v0.19.0/docs/tasks.md) and [project specification](https://github.com/littleboylinlin/New_World/blob/v0.19.0/docs/newworld-format.md) for other limits.
