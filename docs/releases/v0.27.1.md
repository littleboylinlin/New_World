## v0.27.1 更新内容

- **修复 Windows 自动更新装不上**　之前安装新版时，安装程序要先从 GitHub 下载语言包，国内网络连不上 GitHub 时会等很久，然后放弃安装，重新打开还是旧版本。现在安装包自带中英文语言包，安装和更新都不再需要联网下载语言包。
- **语言包优先走国内镜像**　切换语言、macOS 更新时需要下载语言包的地方，都改为先从国内镜像下载，失败再改用 GitHub，每份文件都会校验。

### 兼容性

书库数据库仍为 v11，工程仍使用 Schema 3，全库备份仍使用格式 2。

### 下载

- Windows 11 x64 — `New-World-Setup-0.27.1-x64.exe`
- macOS 13+ Apple Silicon — `New-World-0.27.1-macos-arm64.dmg`
- macOS 13+ Intel — `New-World-0.27.1-macos-x64.dmg`
- 语言包 — `New-World-lang-zh-CN.json`、`New-World-lang-en.json`

可用同页的 `SHA256SUMS.txt` 校验下载文件，也可在「设置 → 更新与关于 → 检查更新」安装适合当前平台的版本。

## What's New in v0.27.1

- **Windows updates install again**　The installer used to download a language pack from GitHub before installing. Where GitHub was slow or unreachable, it waited a long time and then gave up, leaving the old version in place. The installer now carries both language packs, so installing and updating no longer download one.
- **Language packs try the mirror first**　Changing the language, and updating on macOS, now download language packs from the mirror first and fall back to GitHub, checking every file.

### Compatibility

The library database remains at v11, projects still use Schema 3, and full-library backups still use format 2.

### Downloads

- Windows 11 x64 — `New-World-Setup-0.27.1-x64.exe`
- macOS 13+ Apple Silicon — `New-World-0.27.1-macos-arm64.dmg`
- macOS 13+ Intel — `New-World-0.27.1-macos-x64.dmg`
- Language packs — `New-World-lang-zh-CN.json`, `New-World-lang-en.json`

Verify the files against `SHA256SUMS.txt` on the release page, or use “Settings → Updates & about → Check for updates” to install the version for your platform.
