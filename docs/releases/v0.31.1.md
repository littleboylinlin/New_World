## v0.31.1 更新内容

这一版新增反馈与建议入口，遇到问题或有想法时可以直接告诉作者。

- **反馈与建议**　在「设置 → 更新与关于」展开「反馈与建议」，可以选择「报告 Bug」「提建议」或「发邮件」。前两个会打开 GitHub 上对应的表单，发邮件会写给 feedback@writenewworld.com。表单和邮件只预填版本号和平台，不会带上作品名、正文、设定或任何本地数据。桌面版用系统浏览器或邮件客户端打开。
- **反馈表单**　GitHub 上提供中英双语的 Bug 反馈和功能建议表单，按提示填写复现步骤、预期结果或建议内容，可附截图。
- **官网**　页脚新增「反馈」链接和反馈邮箱，跟随中英文切换。

### 下载

- Windows 11 x64 — `New-World-Setup-0.31.1-x64.exe`
- macOS 13+ Apple Silicon — `New-World-0.31.1-macos-arm64.dmg`
- macOS 13+ Intel — `New-World-0.31.1-macos-x64.dmg`
- 语言包 — `New-World-lang-zh-CN.json`、`New-World-lang-en.json`

可用同页的 `SHA256SUMS.txt` 校验下载文件，也可在「设置 → 更新与关于 → 检查更新」安装适合当前平台的版本。

### 兼容性

- 本版不改变数据格式：书库仍为 IndexedDB v14，全库备份格式 5，单部 `.newworld` 工程 Schema 4，与 v0.31.0 互通。
- 从 v0.30.0 及更早版本升级时的说明见 [v0.31.0 发行说明](v0.31.0.md)。

## What's New in v0.31.1

This release adds a feedback entry so you can report problems or share ideas directly.

- **Feedback** — Expand “Feedback” in “Settings → Updates & about” to report a bug, suggest a feature or send an email. The first two open the matching form on GitHub; email goes to feedback@writenewworld.com. Forms and emails are prefilled with only the version and platform — never work titles, text, story settings or other local data. The desktop app opens them in your system browser or mail client.
- **Feedback forms** — GitHub now offers bilingual bug report and feature request forms with fields for steps to reproduce, expected results or your suggestion, plus optional screenshots.
- **Website** — The footer adds a Feedback link and the feedback email address, following the language switch.

### Downloads

- Windows 11 x64 — `New-World-Setup-0.31.1-x64.exe`
- macOS 13+ Apple Silicon — `New-World-0.31.1-macos-arm64.dmg`
- macOS 13+ Intel — `New-World-0.31.1-macos-x64.dmg`
- Language packs — `New-World-lang-zh-CN.json`, `New-World-lang-en.json`

Verify the files against `SHA256SUMS.txt` on the release page, or use “Settings → Updates & about → Check for updates” to install the version for your platform.

### Compatibility

- No data format changes: the library stays on IndexedDB v14, full-library backups use format 5 and `.newworld` projects use Schema 4, fully compatible with v0.31.0.
- If you are upgrading from v0.30.0 or earlier, see the [v0.31.0 release notes](v0.31.0.md).
