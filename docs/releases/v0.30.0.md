## v0.30.0 更新内容

这一版把保存失败后的救稿入口放到台前，补全全库备份的 AI 防丢基线，并新增 EPUB 电子书导出。

- **保存失败横幅优先救稿**　保存失败时，横幅直接提供「重试」和「导出本章」两个主要按钮，复用现有重试保存与导出逻辑并默认仅勾选当前未保存章节，确保没落盘的正文能第一时间救出；「放弃本章未保存改动」降为视觉更弱的次要操作，点击仍需二次确认，避免误触丢稿。
- **全库备份补上 AI 防丢基线**　全库备份升级至格式 3，打包并恢复每章的 `aiBaselines`（AI 防累计内容损失基线）。继续兼容恢复格式 1 与格式 2 旧备份；旧备份不含基线数据时，恢复会清空本机已有基线，避免把不匹配的本地基线套用到恢复出的正文上。
- **新增 EPUB 导出**　导出弹窗新增 EPUB 格式，按作品章节结构导出为一章一个文件的 EPUB 3 电子书，并附带 `toc.ncx` 兼容旧阅读器；写入书名、作者（如有）、语言和唯一标识符，并打包作品封面与正文中的本地插图。
- **更新 README**　核对并更新中英文 README，把已上线的版本历史、AI 辅助、柔纸主题和 EPUB 导出整理为已有功能，同步数据库 v11 与全库备份格式 3 等信息。

### 兼容性

书库数据库仍为 v11，工程仍使用 Schema 3。全库备份写入格式 3，继续兼容读取格式 1 和格式 2（读取不含 `aiBaselines` 的旧备份时清空本机基线）。旧版应用会拒绝恢复格式 3 备份，如需回退请在升级前保留一份旧格式备份。

## What's New in v0.30.0

This release puts draft-rescue controls first when saving fails, includes AI cumulative-loss baselines in full-library backups, and adds EPUB export.

- **Save-failure banner puts rescue first**　When saving fails, the banner now places **Retry** and **Export this chapter** up front, reusing existing retry and export flows with the unsaved chapter pre-selected so uncommitted text can be rescued right away. **Discard unsaved changes in this chapter** is demoted to a quieter secondary action behind secondary confirmation.
- **AI baselines in full-library backups**　Full-library backups move to format 3 to pack and restore `aiBaselines` alongside works and revision history. Legacy format 1 and format 2 backups still restore cleanly with empty baselines, clearing any mismatched local baselines instead of associating them with restored content.
- **EPUB export**　Works can now be exported as EPUB 3 (one file per chapter) with `toc.ncx` for older readers, including title, author (when set), language, unique identifier, custom cover, and embedded local illustrations.
- **README updates**　Updated both `README.md` and `README.en.md` to move shipped features (such as version history and AI assistance) out of planned, document EPUB export and Soft Paper theme, and align database (v11) and backup format (3) notes.

### Compatibility

The library database remains at v11 and `.newworld` projects remain at Schema 3. Full-library backups write format 3 while still reading formats 1 and 2 (clearing local baselines when restoring backups without `aiBaselines`). Older versions of New World reject format 3 backups; keep a pre-upgrade backup if you might roll back.
