## 作品信息与可扩展工程元数据

- **可选作品信息**：原创库与续写／仿写库支持作者、副标题、多段简介、多个标签和创作状态。新建时可填写，也可从作品菜单或详情的「编辑作品信息」修改或清空；已有作品不会被填入默认作者或状态。
- **Schema 2 扩展机制**：`.newworld` 增加独立的 `metadata` 对象，保存作品信息和符合安全约束的未知 JSON 扩展。编辑、备份、导入副本及再次导出会保留扩展值；未知扩展只作为惰性数据，不执行代码、不加载外部资源，也不被误当作需要重映射的身份引用。无法安全保留的类型、未知结构字段和超限数据会明确拒绝。
- **可选正文前言**：TXT、Markdown、HTML、DOCX、PDF 可独立选择是否包含作品标题及副标题、作者、简介，三个选项默认关闭。DOCX/PDF 可在正文前排版作品介绍，继续复用现有正文转换器。
- **保留现有工程数据与组织**：继续保留全部版本、章节、Tiptap 富文本、原始文件字节、封面与图片、批注及自定义颜色、灵感、历史、回收记录和真实关联。并发信息修改检查防止覆盖其他窗口的更新；移除和恢复续写工程首个原文保留当前作品信息。

### 兼容性与限制

- **v0.18.1 读取 Schema 1 和 2，导出始终使用 Schema 2**。导入已发布的 Schema 1 工程不补造作品信息；再次导出会生成 Schema 2。工程 Schema 与应用版本分别管理。
- **旧版 v0.18.0 无法读取 Schema 2**。需要交换新工程的设备应使用 v0.18.1；不承诺旧软件能够读取未来格式，未支持的 Schema 会明确拒绝。
- 未知元数据仅限受约束的纯 JSON：每部作品的 `metadata` 最多 **128 KiB UTF-8**，并限制深度、节点、键和数组数量；保留键、二进制与可执行类型不允许进入该对象。其他结构不做猜测或静默丢弃。现有 SHA-256、ZIP 路径、大小／压缩率、资源和引用校验保持有效。详见[格式规范](https://github.com/littleboylinlin/New_World/blob/v0.18.1/docs/newworld-format.md)。
- 本地书库继续使用 **IndexedDB v8**，不批量重写旧作品。`.newworld` 仍是完整作品副本，导入后的修改保存在本地书库，**不会自动写回来源文件**；更新工程文件须重新导出。全局设置、凭据和无关作品仍排除在工程之外。
- 正文格式不携带完整工程专属数据；本版没有新增 EPUB 导出器、待办或 AI 协作功能。

提供 [Schema 1 示例](https://github.com/littleboylinlin/New_World/blob/v0.18.1/docs/examples/雾港.newworld) 和 [Schema 2 作品信息示例](https://github.com/littleboylinlin/New_World/blob/v0.18.1/docs/examples/雾港-作品信息.newworld)。

本版提供 Windows x64、macOS Apple Silicon（arm64）及 Intel（x64）安装包，简体中文和英语语言包，以及 `SHA256SUMS.txt`。应用内「设置 → 更新与关于 → 检查更新」按平台和芯片选择安装包。继续使用既有签名方式：Windows 安装包未做 Authenticode 签名，macOS 使用本地签名、未作 Developer ID 公证。

## Work Information and Extensible Project Metadata

- **Optional work information**: Original and continuation/imitation works support author, subtitle, multiline synopsis, multiple tags and creative status. Fill these during creation or update and clear them through “Edit work information.” Existing works receive no default author or status.
- **Schema 2 extension envelope**: `.newworld` adds a dedicated `metadata` object for work information and safe, bounded unknown JSON extensions. Edits, backups, independent copies and project round trips retain extension values. Extensions remain inert: they execute no code, load no external resources and are not interpreted as identity references. Unsupported types, unknown structural fields and oversized data are explicitly rejected.
- **Optional manuscript introductions**: TXT, Markdown, HTML, DOCX and PDF exports offer separate title/subtitle, author and synopsis options, all off by default. DOCX/PDF can place work information before the manuscript using the existing converters.
- **Existing project data and organization remain intact**: Retains editions, chapters, Tiptap rich text, original bytes, covers and images, annotations and custom colors, ideas, history, trash and real relationships. Information saves detect concurrent changes; removing and restoring a continuation project's first source preserves its current work information.

### Compatibility and Limitations

- **v0.18.1 reads Schema 1 and 2, and always writes Schema 2**. Published Schema 1 projects import without invented metadata; exporting them again produces Schema 2. Project Schema versions remain independent of application versions.
- **Older v0.18.0 cannot read Schema 2**. Devices exchanging new projects need v0.18.1; older software is not promised future-format compatibility, and unsupported schemas are explicitly rejected.
- Unknown metadata is restricted to plain JSON: at most **128 KiB UTF-8 per work**, with depth, node, key and array budgets. Reserved keys, binary and executable types are prohibited in this object. Other structures are not guessed or silently discarded. Existing SHA-256, ZIP path, size/compression, resource and reference checks remain effective. See the [format specification](https://github.com/littleboylinlin/New_World/blob/v0.18.1/docs/newworld-format.md).
- Local storage remains **IndexedDB v8**, without rewriting existing works. A `.newworld` file remains a complete work copy. Changes after import stay in the local library and **are not automatically written back**; export again to update the file. Global settings, credentials and unrelated works remain excluded.
- Manuscript formats do not carry complete project-specific data. This release adds no EPUB exporter, to-do or AI collaboration features.

Includes [Schema 1](https://github.com/littleboylinlin/New_World/blob/v0.18.1/docs/examples/雾港.newworld) and [Schema 2 metadata](https://github.com/littleboylinlin/New_World/blob/v0.18.1/docs/examples/雾港-作品信息.newworld) samples.

Downloads include Windows x64, macOS Apple Silicon (arm64) and Intel (x64) installers, Simplified Chinese and English language packs, and `SHA256SUMS.txt`. Use “Settings → Updates & about → Check for updates” to select the matching platform and architecture. Signing remains unchanged: Windows installers are not Authenticode-signed; macOS uses a local signature without Developer ID notarization.
