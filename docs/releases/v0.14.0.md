## 作品卡片

- 书名移到封面下方，卡片上的按钮改为书名旁的下拉箭头；右键卡片也能打开同一菜单，可以用方向键选择、`Esc` 关闭。
- 可以为作品上传自定义封面（PNG、JPEG、WebP、GIF、AVIF、BMP，最大 32 MB），原图保存在本地不压缩，也可以随时恢复默认封面。

## 灵感速记

- 桌面版在任何地方按全局快捷键（默认 `Ctrl + Alt + N`，Mac 为 `⌃⌥N`）弹出置顶小窗记灵感；快捷键可在设置里更换或关闭，被占用时会提示。网页版在页面里按 `Ctrl + Alt + N`。
- 首页新增「灵感」，可标记已用、关联作品、复制和删除（可撤销）；灵感默认关联最近打开的作品。
- 编辑器旁的「灵感」面板列出本作品未用的灵感，可一键插入正文。

## 菜单

- 托盘菜单新增记灵感、新建小说、最近的作品、灵感、立即备份和打开备份文件夹。
- 选中文字后右键可「存为灵感」；章节目录右键可新建、重命名、移动和删除章节。
- Windows 任务栏图标右键和 Mac Dock 菜单可以直接记灵感。

## 备份

- 备份现在包含自定义封面、写作统计和灵感。用旧版备份恢复时保留当前灵感。
- IndexedDB 升级到 v5，新增 `ideas` 存储，旧库打开时自动升级。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Work cards

- The title now sits below the cover, and the card buttons become a drop-down arrow beside the title; right-clicking the card opens the same menu, which works with the arrow keys and `Esc`.
- Upload a custom cover (PNG, JPEG, WebP, GIF, AVIF or BMP, up to 32 MB), kept locally at full quality, or switch back to the default cover at any time.

## Quick notes

- On the desktop, press the global shortcut anywhere (`Ctrl + Alt + N` by default, `⌃⌥N` on a Mac) to open a small always-on-top note window; change or turn off the shortcut in Settings, which warns when another app uses it. On the web, press `Ctrl + Alt + N` on the page.
- "Notes" on the home page lets you mark notes used, link them to a work, copy them and delete them (with undo); new notes link to the work opened most recently.
- The "Notes" panel beside the editor lists this work's unused notes and inserts one into the text in a click.

## Menus

- The tray menu adds Quick note, New novel, Recent Works, Notes, Back Up Now and Open Folder.
- Right-click selected text to "Save as Note"; right-click a chapter to add, rename, move or delete chapters.
- The Windows taskbar icon and the Mac Dock menu can open a quick note directly.

## Backups

- Backups now include custom covers, writing stats and notes. Restoring an older backup keeps your current notes.
- IndexedDB is upgraded to v5 with a new `ideas` store; existing libraries upgrade automatically on open.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
