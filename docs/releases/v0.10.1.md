## 界面选择行为

- Windows 和 macOS 的导航、按钮、书库卡片及界面说明不再随鼠标拖动被框选。
- 正文编辑、阅读模式、原文件文本预览和导出文本预览仍可选择复制，输入框的编辑与全选正常；设置中的存储路径和更新说明也可复制。
- 移除左上角“小说管理器”及对应英文副标题，顶栏保留 New World。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Text selection

- Navigation, buttons, library cards, and interface labels no longer become selected when dragging on Windows or macOS.
- Manuscripts, reading mode, source text previews, and export text previews remain selectable. Input fields still support editing and selecting text; storage paths and release notes can also be copied.
- Remove the “Novel library” subtitle from the top-left corner, leaving New World in the header.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
