## v0.24.0 更新内容

- **编辑器改版**　编辑页面固定不滚动，只有正文区域滚动，顶部工具栏始终可见。工具栏按用途分组：章节切换与保存状态、撤销与重做、文字格式、插入，以及查找、外观、专注、侧面板和「⋯」。不常用的命令收进「⋯」，窄屏时按优先级依次收起。作品信息、版本切换、作品任务和下载原文件移到作品名菜单里。
- **选中文字工具条**　选中正文后稍等片刻，旁边会出现加粗、斜体、记灵感、建任务等工具，拖动选择时不会出现。取消选区后工具条消失。触屏设备上工具条在工具栏下方滑出，不与系统菜单重叠。
- **外观合并**　原来的外观菜单和版式弹窗合并为一个「Aa」面板，与设置页读写同一套偏好。
- **查找**　查找在工具栏内展开，显示命中总数和当前位置，可上一个、下一个并自动滚动到结果。可切换「本章」和「全书」，全书模式按章列出命中数并可直接跳转。支持区分大小写、全字匹配，以及本章内替换和全部替换。
- **章节管理**　章节顺序可以直接拖动调整，也可用键盘调整。改名和删除移到右键菜单与悬停时出现的「⋯」。
- **分块与对照阅读**　从章节目录或右侧「对照」标签把条目拖进编辑区，落点会先显示预览，松手即在该位置分出新块，可左右、上下以及四分之一排列，分隔线可拖动调整大小。对照块为只读，可选中复制、摘进灵感；本作品其他章可一键切换为编辑。只有原文件的作品也能直接对照预览。桌面版可在新窗口打开对照。窄屏时对照内容在抽屉中打开。
- **网页块（桌面版）**　可在编辑区旁打开网页查资料。每个网页块使用独立的内存会话，不在本机保存 Cookie、缓存、浏览记录或登录状态，关闭网页块或退出应用时全部清空。网页无法访问应用数据，权限请求一律拒绝，证书错误的网站会被拦截。网页中选中的文字可以摘进灵感或转成待办，是否附带链接由你决定。搜索引擎可在设置中选择。
- **灵感链接**　灵感里的网址可以点击：桌面版在网页块中打开，网页版在新标签页打开。
- **记住状态**　目录与侧面板的开关、查找选项、外观、分块布局和各块内容都会保存在本机；打开任何章节都从上次停留的位置继续。
- **动画**　菜单、面板、工具条、分块和抽屉的展开与收起都有过渡动画；开启系统的「减少动态效果」时直接切换。

### 兼容性

书库数据库仍为 v10，工程仍使用 Schema 3，全库备份仍使用格式 2。新增的界面状态只保存在本机。

## What's New in v0.24.0

- **Redesigned editor**　The editor page no longer scrolls as a whole: only the text scrolls, and the editor toolbar always stays in view. The toolbar is grouped by purpose: chapter switching and save status, undo and redo, text formatting, insert, and find, appearance, focus, side panels, and “⋯”. Less frequent commands live under “⋯”, and on narrow screens tools move there in order of priority. Work details, versions, work tasks, and downloading the original file are now in the work name menu.
- **Tools for selected text**　Shortly after you select text, bold, italic, idea, and task tools appear beside the selection. They stay hidden while you are still dragging and disappear when the selection is cleared. On touch screens the tools slide out below the toolbar so they do not overlap the system menu.
- **One appearance panel**　The appearance menu and layout dialog are now a single “Aa” panel that shares its preferences with Settings.
- **Find**　Find opens inside the toolbar and shows the number of matches and your position. Next and previous scroll to each match. Switch between this chapter and the whole book; the whole-book view lists matches per chapter and jumps straight to them. Match case, whole words, and replace or replace all within the chapter are supported.
- **Chapters**　Drag chapters to reorder them, or reorder them with the keyboard. Rename and delete are in the context menu and in the “⋯” that appears on hover.
- **Panes and side-by-side reading**　Drag an entry from the chapter list or the Compare tab into the editor. A preview shows where it will go, and releasing opens a new pane there: side by side, stacked, or in quarters, with dividers you can drag to resize. Side-by-side text is read-only and can be copied or saved as an idea; another chapter of the same work can be switched to editing in one step. Works stored only as an original file open as a preview. On desktop, side-by-side text can also open in a new window. On narrow screens it opens in a drawer.
- **Web pane (desktop)**　Open web pages beside the text for research. Each web pane uses its own in-memory session: cookies, cache, history, and sign-ins are never saved on this device and are cleared when you close the pane or quit the app. Web pages cannot access your library, permission requests are always denied, and sites with certificate errors are blocked. Selected text can be saved as an idea or a task, with the link included only if you choose. The search engine can be changed in Settings.
- **Links in ideas**　Web addresses in ideas are now links: on desktop they open in a web pane, and on the web they open in a new tab.
- **Remembered state**　The chapter list and side panels, find options, appearance, pane layout, and pane contents are saved on this device, and every chapter reopens where you left off.
- **Motion**　Menus, panels, toolbars, panes, and drawers open and close with transitions. With your system's reduced motion setting on, they switch instantly.
