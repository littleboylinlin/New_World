## 窗口按钮

- Windows 桌面端改用应用自绘的最小化、最大化／还原和关闭按钮，替换系统原生标题栏按钮；悬停右上角不再弹出「Close」等系统提示。按钮提供中英文无障碍名称，关闭前仍会自动保存未保存的正文，最大化与还原状态随窗口同步。
- macOS 保留原生红黄绿窗口按钮，不受影响。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Window buttons

- The Windows desktop app now draws its own minimize, maximize/restore, and close buttons in the header instead of the native title-bar overlay, so hovering the top-right corner no longer pops up a system "Close" tooltip. The buttons expose Chinese and English accessible names, closing still saves unsaved text first, and the maximize/restore icon tracks the window state.
- macOS keeps its native red/yellow/green window buttons, unchanged.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
