## v0.31.3 更新内容

这一版修复了菜单关闭时的一个小问题。

- **菜单关闭更干净**　菜单和浮层关闭时会淡出一小会儿，以前这段时间里它还能被点到，读屏软件也会把它当成打开的菜单。快速关掉一个菜单再打开另一个时，可能同时出现两个菜单。现在菜单一开始关闭就不再响应点击，也不会被读屏读到，焦点照常回到原来的按钮上。

## What's New in v0.31.3

This release fixes a small issue when menus close.

- **Cleaner menu closing** — Menus and popovers fade out briefly when they close. During that moment they could still be clicked, and screen readers still treated them as open, so closing one menu and quickly opening another could leave two menus on screen. A menu now stops taking clicks and is hidden from screen readers as soon as it starts closing, and focus still returns to the button that opened it.
