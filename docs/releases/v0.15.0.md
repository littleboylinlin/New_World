## 本地 AI 接入与权限控制

- 桌面端新增完全离线的本地 HTTP `/v1` 接口（默认关闭），启用后仅监听 `127.0.0.1` 回环地址，拒绝非回环与伪造 `Host` / `Origin` / `Sec-Fetch-Site` 请求，严格通过现有业务层与数据校验读写书库，不直接暴露底层 IndexedDB 或密钥，支持作品/章节读写建删、章节顺序调整、原创库与续写库关联及范围过滤搜索，并附完整协议文档 `AI_INTEGRATION.md`。
- 在「设置 → AI 接入与权限」中支持创建多个独立隔离的 AI 配置、一次性展示 Bearer 令牌（仅保存 SHA-256 哈希）、轮换或撤销令牌；四项 CRUD 权限（Create / Read / Update / Delete）与访问范围（「禁止访问 / 仅允许指定小说 / 允许访问整个小说库」）默认全部关闭，变更和撤销立即生效并记录本地审计日志。
- 删除及通过 Update 造成的大幅内容削减/批量删章均实施不可绕过的强制人工二次确认：即使已授 Delete 权限，每次操作也必须由用户本人在原生弹窗手动点击确认，严禁通过 API 自行确认、复用或批量预授权，不提供关闭该保护的设置。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Local AI access & fine-grained permissions

- Adds an offline localhost HTTP `/v1` interface on Windows and macOS (off by default, strictly bound to `127.0.0.1`), rejecting non-loopback requests and forged `Host` / `Origin` / `Sec-Fetch-Site` headers. Operations execute through the existing business layer—covering works, chapters, reordering, original/reference continuation links, and scope-filtered search—without exposing IndexedDB or keys (see `AI_INTEGRATION.md`).
- "Settings → AI Access & Permissions" lets you create isolated AI profiles with one-time Bearer tokens (stored as SHA-256 hashes only), rotate or revoke tokens immediately, configure default-off CRUD flags independently, and pick no access, selected novels, or full-library access, backed by local audit logs.
- Deletions and destructive updates (single-step wipes, cumulative >65% content reductions, and batch chapter removals) always enforce a non-bypassable manual confirmation dialog in the app UI—never self-approved by API, reused, or disabled.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
