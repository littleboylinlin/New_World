## v0.23.0 更新内容

- **平滑光标**　打字时光标会带一点阻尼滑到新位置，停手后最多 150 毫秒到位。连续快速输入时光标最多落后约一个半字，不会被越甩越远。打字自然折到下一行时，光标先回到行首，再滑到新的一行。长按输入或删除、鼠标点击、方向键和 Home/End、全选、粘贴、撤销等操作仍然直接到位。系统开启「减少动态效果」时一律直接到位。
- **拼写框**　用输入法打中文时，还没上屏的拼音会显示浅色底的拼写框，深浅主题下都清楚，光标跟在拼音末尾。选词后拼写框立刻消失，光标从拼音末尾滑到汉字末尾；按 Esc 取消时不会留下多余文字。上屏后撤销一次会撤掉整个词。系统候选窗口仍然贴着输入位置。
- **所有输入框一致**　正文、灵感、桌面速记小窗、任务的标题和描述以及评论、作品名和作品信息、重命名、搜索框、设置里的文本框和阅读批注，都使用同样的平滑光标和拼写框。手机和平板上同样有平滑光标和拼写框；长按调出放大镜或拖选文字时交给系统处理，松手后恢复。
- **桌面版标题栏**　顶栏只保留应用图标，NEW WORLD 移到侧栏顶部、收起按钮左边。收起侧栏时名字随侧栏平滑隐藏，展开时回来。窄窗口下，名字显示在抽屉顶部。网页版布局不变。
- **问题修复**　在任务搜索框里用输入法打字时，组字不会再被打断。在 iPhone 上，作品信息、速记等弹窗变矮后可以在弹窗内部滚动，底部的保存按钮不再被遮挡。

### 兼容性

书库数据库仍为 v10，工程仍使用 Schema 3，全库备份仍使用格式 2，均没有变化。本次更新只涉及界面，不改动任何已保存的数据。

## What's New in v0.23.0

- **Smooth caret**　While you type, the caret glides to its new position with a little damping and settles within 150 ms after you stop. During fast typing it trails by at most about one and a half characters, so it never falls further and further behind. When text wraps to the next line, the caret returns to the start of the line and then slides down. Holding a key to repeat or delete, clicking, arrow keys and Home/End, selecting all, pasting, and undoing still move the caret at once. When Reduce motion is turned on in the system, the caret always moves at once.
- **Composition box**　When you type with an input method, the reading that has not been committed yet is shown in a box with a light background, clear in both light and dark themes, and the caret follows its end. When you choose a word, the box disappears at once and the caret slides from the end of the reading to the end of the word. Pressing Esc to cancel leaves no extra text behind. A single undo after committing removes the whole word. The system candidate window still stays next to the text you are typing.
- **Every text field**　The chapter text, ideas, the Quick capture window, task titles, descriptions, and comments, work titles and work information, renaming, search boxes, text fields in Settings, and annotations all use the same smooth caret and composition box. Phones and tablets also get the smooth caret and composition box; when you press and hold for the magnifier or drag to select text, the system takes over until you lift your finger.
- **Desktop title bar**　The title bar now shows only the app icon. NEW WORLD moves to the top of the sidebar, left of the Collapse sidebar button. When you collapse the sidebar, the name fades away with it, and it returns when you expand the sidebar. In narrow windows, the name appears at the top of the drawer. The web layout is unchanged.
- **Fixes**　Typing with an input method in Search tasks is no longer interrupted mid-word. On iPhone, dialogs such as work information and quick capture scroll inside when they get short, so the Save button at the bottom is no longer hidden.

### Compatibility

The library database remains at v10, projects still use Schema 3, and full-library backups still use format 2. None of these changed. This update only changes the interface and does not alter any saved data.
