## 平滑写作

- **平滑光标**：光标高度跟随当前行字号，颜色跟随主题，短距离移动使用约 75ms 过渡并保留闪烁。选中文字或失去焦点时隐藏；输入法组合期间保持上一次确认的位置，结束后同步。窗口缩放、滚动、字体加载、图片和表格布局变化后重新定位。
- **降低输入负担**：字数统计、章节大纲和正文搜索结果在停笔约 400ms 后更新，自动保存等待约 500ms。连续输入期间不反复扫描全文或生成保存快照。手动保存和离开章节仍立即保存，快速切章前补齐字数，避免全书字数少算。
- **可选打字机模式**：在「设置 → 外观 → 打字机模式」开启，默认关闭。输入和换行时将当前行保持在编辑区中央附近；手动滚动浏览会停止跟随，再次输入后恢复，不主动抢回焦点。
- **减少动态效果**：系统开启「减少动态效果」后，光标直接跟随、居中滚动不使用平滑过渡。

## Smooth Writing

- **Smooth caret**: The caret follows the current line's text size and theme, with an approximately 75ms transition for short moves and normal blinking. It hides for a selection or loss of focus, stays at the last committed position during IME composition, and resynchronizes when composition ends. Zoom, scrolling, font loading, images and table layout changes update its position.
- **Less work while typing**: Word counts, the chapter outline and search results update after about 400ms without typing; autosave waits about 500ms. Continuous typing no longer repeatedly scans the chapter or serializes save snapshots. Manual saves and leaving a chapter still save immediately, and a quick chapter switch first updates the count so the book total stays correct.
- **Optional typewriter mode**: Enable it in “Settings → Appearance → Typewriter mode”; it is off by default. Typing and newlines keep the current line near the middle of the editor. Scrolling to browse pauses following until you type again, without moving focus back.
- **Reduced motion**: With the system's reduced-motion preference enabled, caret movement and centering are immediate.

### Compatibility

Database v9, project Schema 3 and full-library backup format 2 remain as in v0.19.0, with no additional database migration. Projects in Schema 1/2/3 and backups in format 1/2 remain readable. Typewriter mode is a device preference, not part of chapter text or project files.

When upgrading from v0.18.1 or earlier, first read the [v0.19.0 backup and rollback guidance](https://github.com/littleboylinlin/New_World/releases/tag/v0.19.0).

### Validation

The [feature validation run](https://github.com/littleboylinlin/New_World/actions/runs/44093749212) passed 224 browser tests, 15 Windows installed-app tests and 8 tests for each macOS architecture. Coverage includes caret placement, selections, focus, composition, reduced motion, layout changes, typewriter settings and quick chapter switches.

A 115,000-character chapter with 1,000 paragraphs was exercised through 60 consecutive editing transactions. Desktop synchronous transaction P95 was 2.6–4.2ms, with no full-chapter counts or save snapshots during continuous typing. These are synchronous transaction timings on the test machines, not complete input-to-display latency on every device. Composition is covered by automated events and Chromium's IME protocol; physical system IME candidate windows were not manually tested. This version's installers are subject to the release workflow's build, installation tests and asset hash checks.
