## v0.32.0 更新内容

每部作品现在都有自己的「伏笔箱」。埋下的线索、人物的承诺、物品的去向，都可以先写个标题，等写到后面再补充。

- **从作品菜单打开伏笔箱。** 可以搜索标题和描述，查看全部、未回收或已回收的记录。回收状态随时可改，位置和备注会保留。
- **在章节旁查看伏笔。** 编辑器侧栏的「伏笔」只显示与本章有关的记录。每条伏笔可关联多个埋设或回收章节，点击章节名即可跳转。章节改名或调整顺序后仍可跳转。删除章节后，原有位置说明仍在，可重新选择章节，也可从回收站恢复原章节。
- **记录随作品保存。** 伏笔自动保存，随全库备份和单部 `.newworld` 工程一起转移。TXT、Markdown、HTML、PDF、EPUB 和 DOCX 正文导出均不包含伏笔。

### 兼容性

- **如需回退，请保留升级前的全库备份。** 首次打开会将书库升级到 IndexedDB v15，只新增伏笔表，原有记录无需改写。v0.31.3 及更旧版本无法打开升级后的书库。
- 本版写入全库备份格式 6 和 `.newworld` Schema 5，同时读取旧备份格式 1–5 和旧工程 Schema 1–4。两个新格式需要 v0.32.0 或更新版本。旧备份按原有的全库替换流程恢复，恢复后的伏笔箱为空。

## What's New in v0.32.0

Each work now has a place to keep track of foreshadowing and continuity. Give a clue, a promise, or a missing object a title and fill in the details when you come back to it.

- **Open Foreshadowing from the work menu.** Search titles and descriptions, filter by status, and change a clue's status while keeping its notes and locations.
- **See clues beside the current chapter.** The editor's Clues tab lists entries linked to the chapter. Each entry can link to several setup or payoff chapters. Links follow chapters through renames and reordering. If a chapter is deleted, the location note stays with the entry. You can choose another chapter or restore the original from Trash.
- **Entries save with the work.** Foreshadowing saves automatically and travels with full-library backups and single-work `.newworld` projects. TXT, Markdown, HTML, PDF, EPUB, and DOCX manuscript exports leave those notes private.

### Compatibility

- **Keep a full-library backup from before upgrading if you may need to roll back.** The first launch upgrades the library to IndexedDB v15 by adding a foreshadowing store. v0.31.3 and earlier cannot open the upgraded library.
- This version writes backup format 6 and `.newworld` Schema 5. It also reads earlier backups in formats 1–5 and projects in Schemas 1–4. The new files require v0.32.0 or later. Restoring an older backup replaces the library as usual and starts with an empty foreshadowing box.
