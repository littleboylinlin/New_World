## 独立分类设置页面与一屏桌面首页工作台重构

- **独立设置页面与左下角入口**：废弃原有设置弹窗浮层，将设置重构为完整的应用内部独立页面（支持 `#/settings/<分类>` 路由与默认规范化至 `#/settings/general`），设置入口从顶部栏移至左下角独立位置并在设置页显示当前激活状态（专注写作模式自动隐藏）。
- **固定左侧分类导航与独立右侧内容区**：左侧分类导航栏固定于设置页左侧且支持键盘方向键／Home／End 切换，右侧仅展示当前选中的单一分类，完整覆盖 **常规**、**外观**、**快捷记录**、**存储**、**备份与恢复**、**AI 接入** 与 **更新与关于** 七个分类；内置清晰返回按钮回到进入设置前的页面，并在跨分类切换时持续保留异步检查状态、任务锁与已显露 AI 令牌。
- **正常桌面窗口一屏首页布局**：重构首页标题栏与双入口（**灵感笔记**、**已归档作品**）、左右并排的 **原创小说** 与 **续写 / 仿写** 双书库卡片及紧凑型写作统计热力图，使 `1220×850` 与 `1280×720` 等标准桌面窗口下首页完整呈现且无需纵向滚动；在 `480×420` 窄窗与 `390×844`、`320×420` 移动端视口下自然堆叠并保持零横向溢出。
- **保留原有数据与离线本地能力**：此次重构严格限定于界面布局与导航交互，完整保留既有小说书库结构、AI 权限与二次确认保护、备份恢复、回收站与历史版本能力，不新增外部 UI 框架依赖。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Standalone Categorized Settings Page & One-Screen Home Workbench Redesign

- **Standalone settings page & bottom-left dock**: Replaced the former modal dialog overlay with a dedicated in-app settings view (`#/settings/<category>`, canonicalizing `#/settings` to `#/settings/general`). Moved the Settings entry from the top header to an isolated bottom-left footer dock with active `aria-current="page"` state (automatically hidden in Focus writing mode).
- **Pinned category sidebar & mutually exclusive content pane**: Added a pinned left category rail with keyboard Arrow / Home / End navigation alongside an independent right content pane displaying one category at a time across **General**, **Appearance**, **Quick capture**, **Storage**, **Backup & restore**, **AI integration**, and **Updates & about**. Preserves background update/storage locks and revealed AI tokens while switching categories, with a clear Back button returning to the prior route.
- **One-screen desktop Home layout**: Reorganized the Home header, dual **Notes** / **Archive** entries, side-by-side **Original** and **Continuation / Imitation** library cards, and compact writing activity stats so standard desktop windows (`1220×850` and `1280×720`) fit cleanly without vertical or horizontal scrollbars, while stacking responsively at `480×420`, `390×844`, and `320×420` with zero horizontal overflow.
- **Zero data or business-logic regressions**: Strictly scoped to UI/UX layout and navigation; preserves all novel storage formats, offline operation, local AI access controls, confirmations, backups, Trash retention, and revision recovery without adding UI framework dependencies.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
