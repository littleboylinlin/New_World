## macOS 桌面版

- 新增 macOS 13 及以上版本支持，提供 Apple Silicon（arm64）和 Intel（x64）两种 DMG。打开后将 New World 拖入 Applications。
- 适配红黄绿窗口按钮、Mac 应用菜单、Command 快捷键和 PDF 保存。「设置」可从应用菜单或 `⌘ + ,` 打开。
- 书库默认保存在 `~/Library/Application Support/NewWorld`。替换或删除应用不会删除书库；存储位置、后台关闭和语言选择延续原有设置。
- 首次打开按系统语言只获取对应语言包，已下载语言可离线使用。
- Mac 更新检查仅选择本机芯片的 DMG。下载校验后先保存正文并退出，再打开 DMG 完成替换。

本次为 Mac 专用发行版，不包含新的 Windows 安装包。Windows 最新版仍为 v0.8.0，Windows 的「检查更新」会跳过本次发行版。Mac 同样不会因 Windows 专用发行版而更新。

安装包使用本地签名，尚未使用 Apple Developer ID 签名或公证；首次启动可能需要在 macOS 中确认来源。安装包和语言包的 SHA-256 校验值见 `SHA256SUMS.txt`。

## macOS desktop app

- Supports macOS 13 and later, with separate DMGs for Apple Silicon (arm64) and Intel (x64). Drag New World into Applications to install.
- Adapts window controls, the application menu, Command shortcuts, and PDF saving. Open Settings from the app menu or with Command-comma.
- Keeps the library in `~/Library/Application Support/NewWorld`. Replacing the app preserves books and language preferences. Only the selected language pack is downloaded on first launch.
- Update checks select only the DMG matching the current Mac architecture. After download verification, the app saves text and quits before opening the DMG.

This is a Mac-only release. Windows remains on v0.8.0 and will not offer this release as an update. Mac update checks also skip Windows-only releases.

The app is ad-hoc signed and is not Developer ID signed or notarized. macOS may require confirmation on first launch. Verify downloads against `SHA256SUMS.txt`.
