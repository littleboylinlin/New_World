## 阅读批注排版与交互修复

- **行间批注融入现有行间空隙**：使用小字号、低饱和度文字和轻量箭头，背景透明，不再向正文插入大型卡片、附加段落或重复原文。简短预览在可用宽度内显示，空间不足时以省略号截断；紧凑行距下可仅显示箭头。相近端点的批注共用入口，展开后保留每条批注。
- **分别设置字体色和高亮背景色**：行间批注提供独立的文字颜色预设及自定义选择器，只改变批注字体颜色。文字标记模式保留原有高亮背景色；切换展示形式时两种配置分别保存。已有批注、稳定 ID、锚点和颜色配置保持兼容，旧记录无需重写。
- **精简两种模式的浮层**：仅显示用户填写的批注及小图标编辑、删除入口，移除引用原文、重复标题、提示语和「关闭批注」按钮。悬停可预览，移入浮层后继续显示；点击标记或浮层可固定，点击外部、其他标记或按 Escape 收起。浮层按可用空间限制高度，并处理窗口边缘和滚动容器裁切。
- **工具栏在选区结束后出现**：拖动框选期间隐藏「添加批注」，松开鼠标并形成有效选区后，按最终选区定位。支持正反向、跨段落及键盘选择，保留原文复制和正常滚动。
- **稳定合并批注的颜色回归检查**：按批注文本分别核对实际字体色和存储值，覆盖正序、逆序 ID 的合并场景，修复依赖 DOM 末项位置的偶发测试失败。回归覆盖旧数据、透明背景、正文逐行坐标、窄窗口、复制、滚动容器、悬停固定及 Windows 应用重启持久化。

### 已知限制

- PDF 当前为画布预览，暂不支持文字批注；仅下载的格式和图片本身也不提供文字选区批注。
- 锚点采用整章文档级校验。正文、格式或原件解码文字变化后，旧锚点会失效；批注内容仍保留并显示提示，不会静默关联到其他文字。当前版本暂不支持自动重新定位或手动重新锚定。
- 正文导出不包含批注，暂不提供独立批注导出格式。整库备份仍会保留批注数据。

详细说明见 [阅读批注](https://github.com/littleboylinlin/New_World/blob/v0.17.1/docs/reading-annotations.md)。提供 Windows x64、Mac Apple Silicon（arm64）和 Intel（x64）安装包，以及简体中文、英语语言包。使用同页的 `SHA256SUMS.txt` 校验下载文件。

## Reading Annotation Layout and Interaction Fixes

- **Inline annotations fit existing line gaps**: Small, muted text and a lightweight arrow appear on a transparent background, without inserting large cards, extra paragraphs, or repeated source text. Previews truncate with an ellipsis to fit available width; compact line spacing can show only an arrow. Nearby endpoints share an entry that opens all associated annotations.
- **Separate text colors from highlight backgrounds**: Inline annotations have their own text color presets and custom picker, applied only to annotation text. Highlight mode keeps its existing source background color. Both settings survive display-style changes. Existing notes, stable IDs, anchors, and colors remain compatible without rewriting older records.
- **Simpler shared popups**: Popups show only the user's note and compact edit/delete icons. Source quotations, repeated titles, instructional text, and the close button have been removed. Hover to preview and move into the popup to keep reading; click the marker or popup to pin it. Click elsewhere, another marker, or press Escape to dismiss it. Popup height respects available space, window edges, and scrolling containers.
- **Selection controls appear after selection finishes**: “Add annotation” stays hidden while dragging and is positioned from the final selection after mouse release. Forward, reverse, cross-paragraph, and keyboard selections are supported, while source copying and scrolling remain available.
- **Stable color regression checks for merged annotations**: Tests identify each note by text and check its rendered and stored text color in both ascending and descending ID order. This fixes an intermittent assertion that assumed the last DOM item was the most recently created note. Coverage includes legacy data, transparent backgrounds, unchanged source line geometry, narrow windows, copying, scrolling containers, hover/pin behavior, and persistence across Windows app restarts.

### Known Limitations

- PDF previews currently use a canvas and do not support text annotations. Download-only formats and images themselves do not provide text selections for annotations.
- Anchors validate the entire chapter document. Source, formatting, or decoded-text changes invalidate old anchors; notes remain available with a notice and are never silently reassigned to different text. Automatic repositioning and manual re-anchoring are currently unsupported.
- Document exports exclude annotations. A separate annotation export format is currently unavailable; full-library backups still preserve annotation data.
