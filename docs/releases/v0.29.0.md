## v0.29.0 更新内容

这一版继续给界面做减法：去掉大段说明文字，把删除都放进二次确认，并为 Windows 新增一个只有几百 KB 的在线安装包。

- **Windows 在线安装包**　新增 `New-World-Online-Setup-0.29.0-x64.exe`，只有约 700 KB，安装时从国内镜像下载程序本体，并按打包时记下的 SHA-512 校验后才安装。官网的 Windows 下载按钮默认提供在线版，按钮下方保留完整的离线安装包；安装时没有网络，或者想留一份安装包备用，可以继续下载完整版。应用内更新仍使用完整安装包，不受影响。
- **去掉多余的说明文字**　任务、导入导出、设置、外观、灵感、编辑器和 AI 设置里的 60 多段解释性文字已删除，页面更紧凑。会影响数据或隐私的提示都保留了，包括永久删除、备份密码、恢复备份、网页版数据保存、密钥暴露，以及 AI 发送前的确认。
- **删除前二次确认**　在归档页删除作品、删除灵感、撤销本地 AI 配置时，都会先弹窗确认，避免误点。
- **AI 发送确认可以不再提示**　第一次用某套 AI 配置时弹出的发送确认，新增「不再提示」选项，默认勾选；取消勾选后，每次发送前都会再问一次。

### 兼容性

书库数据库仍为 v11，工程仍使用 Schema 3，全库备份仍使用格式 2，旧数据无需迁移。

## What's New in v0.29.0

This release keeps trimming the interface: long help text is gone, every deletion asks first, and Windows gets an online installer of a few hundred KB.

- **Windows online installer**　The new `New-World-Online-Setup-0.29.0-x64.exe` is about 700 KB. While installing, it downloads the app from the mirror and installs it only after checking it against the SHA-512 recorded when it was built. The Windows button on the website now offers the online installer, with the full offline installer just below it for installing without a connection or keeping a copy. In-app updates still use the full installer.
- **Less explanatory text**　More than 60 explanatory paragraphs are gone from tasks, import and export, settings, appearance, ideas, the editor and AI settings. Warnings that protect your data or privacy stay: permanent deletion, backup passwords, restoring a backup, browser storage on the web, key exposure and the confirmation before sending text to an AI service.
- **Confirm before deleting**　Deleting a work from the archive, deleting an idea and revoking a local AI client now ask for confirmation first.
- **AI send confirmation can stay quiet**　The confirmation shown the first time an AI configuration is used has a “Don't ask again” box, checked by default; uncheck it to be asked before every send.

### Compatibility

The library database remains at v11, projects still use Schema 3, and full-library backups still use format 2. No migration is needed.
