## 完整替换与更新清理

- Windows 更新会移除旧程序后安装新版，补充了旧文件消失和正文保留的原生回归。
- Mac 新增应用内整包替换并自动重启：先校验 DMG、芯片、应用身份、版本和代码签名，准备所选语言包；退出后原子交换应用，确认新版界面正常打开后才删除旧包。新版启动失败会恢复原版。
- 两端回收应用管理的更新缓存，在界面正常打开后清理过期语言包和中断写入的临时文件。升级时刷新旧页面和编译缓存，保留 IndexedDB。Mac 还会清理默认下载目录中可识别的旧版中断下载文件。
- 书库、正文、设置、当前版本已下载的语言，以及手动保存的安装包均保留。无法删除的占用文件会重试并在后续启动继续处理。

Mac 的安装目录需要可写。从 v0.9.x 升级仍按旧版流程下载 DMG 并替换一次，此后可用「更新并重启」完成整包替换。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。Windows 未做 Authenticode 签名；Mac 使用本地签名，未做 Developer ID 签名或公证。SHA-256 校验值见 `SHA256SUMS.txt`。

## Full application replacement

- Windows removes the previous program before installing the new version. Native coverage checks that obsolete files disappear while manuscripts remain.
- Mac adds in-app replacement and restart. It verifies the DMG, architecture, application identity, version, and code signature, then prepares the selected language. After quitting, it atomically swaps the whole app and keeps the previous bundle until the new interface is ready. A failed startup restores the previous app.
- Both platforms remove managed update downloads and obsolete language caches. Interrupted temporary files are recovered on later starts; recognizable legacy Mac partial downloads in Downloads are also removed.
- Books, settings, current language caches, and manually saved installers are preserved. Files still in use are retried on a later start.

Mac requires a writable installation location. Upgrading from v0.9.x still uses the existing DMG replacement flow once; subsequent updates support full in-app replacement.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Windows is not Authenticode signed; Mac is ad-hoc signed and is not Developer ID signed or notarized. Verify downloads with `SHA256SUMS.txt`.
