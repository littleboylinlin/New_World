## v0.27.0 更新内容

这一版让 AI 直接住进 New World：在「设置」里接上你自己的 API，就能在编辑器和网页块里随时请它帮忙。New World 不提供代理、不上传也不记录任何内容，文字只发给你自己配置的地址。

- **AI 服务设置**　「设置」新增 AI 服务页，支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 四种协议。Base URL 和请求路径、认证方式、自定义请求头、额外请求参数、模型、生成参数、流式、超时和重试都可以自己填，方便接入各类中转站；模型可以手填，也可以一键获取列表。可以保存多套配置，并给润色、提问、校对、总结分别指定用哪一套；常用服务商有预设，配置可以导入导出（导出不含密钥）。「测试连接」会原样显示状态码和错误信息。桌面版的密钥用系统钥匙串加密保存在本机，请求从应用内部发出；网页版由浏览器直接连接，默认不保存密钥，可以选择「在此设备记住密钥」。第一次使用时会告诉你选中的文字将发送到哪里。
- **框选问 AI**　选中文字后，浮动工具条里多了 AI 入口：润色、改写、扩写、缩写、改语气，也可以就这段内容自由提问。结果边生成边显示，随时可以停止。
- **逐处对照采用**　润色、改写的结果以对照方式标出删改，可以整段采用、逐处采用或拒绝、作为新段落插在后面，或者放弃。采用时保留原文的加粗、斜体和段落；建议显示期间你改了正文，相关的建议会跟着移动或自动失效。采用前会先存一个历史版本，也可以直接撤销。
- **风格库**　可以创建写作风格：描述想要的文风，或者从自己的作品里选几章让 AI 总结出你的文笔。每种风格都能查看和编辑完整的提示词，也能导入导出；内置几套示例风格。润色时可以选用风格，作品可以设默认风格。风格会跟着全库备份一起保存。
- **校对**　检查选区或本章的错别字、病句和标点，结果用同样的对照方式逐处采用。
- **总结**　总结选区、本章或整本。整本总结会记住每章的摘要，下次只重新总结改过的章节，更快也更省 API 费用；摘要缓存可以在设置里清空。结果可以存为灵感。
- **网页块总结（桌面版）**　网页块工具栏新增「总结」，可以总结选中的内容或整页，结果能摘进灵感或转成待办，并可选择是否附带链接。只有点了总结的那一页文字会发给 AI，网页块仍然无痕。
- 原有的本地 AI 接口（v1）保持不变。

### 兼容性

书库数据库升级到 v11（新增写作风格），首次打开时自动完成。工程仍使用 Schema 3，全库备份仍使用格式 2；新备份会带上写作风格，旧备份照常可以恢复。AI 配置、密钥和章节摘要缓存只保存在本机，不进入备份。

## What's New in v0.27.0

This release brings AI into New World itself: connect your own API in Settings, and it is there to help in the editor and in web panes. New World runs no proxy and uploads or records nothing; your text goes only to the address you configure.

- **AI service settings**　Settings has a new AI service page supporting four protocols: OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, and Gemini. Base URL and request paths, authentication, custom headers, extra request parameters, model, generation parameters, streaming, timeout, and retries are all yours to set, so relay services work too; type a model name or fetch the list. Save several profiles and choose which one polishing, questions, proofreading, and summaries use. Common providers come as presets, and profiles can be exported and imported without their keys. “Test connection” shows the status code and error message as they come back. On desktop, keys are encrypted with the system keychain and requests are sent from inside the app; on the web, the browser connects directly and keys are not kept unless you choose “Remember key on this device”. The first time you use it, New World tells you where the selected text will be sent.
- **Ask AI about a selection**　Select text and the floating toolbar offers AI: polish, rewrite, expand, shorten, change tone, or ask your own question about the passage. Results appear as they are written, and you can stop at any time.
- **Accept changes one by one**　Polished and rewritten text is shown against the original with deletions and insertions marked. Accept it all, accept or reject each change, insert it as a new paragraph after the selection, or discard it. Accepted changes keep the original bold, italics, and paragraphs; if you edit the text while suggestions are showing, they move with it or step aside. A revision is saved before the first change is applied, and undo works as usual.
- **Style library**　Create writing styles: describe the voice you want, or pick a few chapters of your own and let the AI sum up how you write. Every style’s full prompt can be viewed, edited, exported, and imported, and a few sample styles are included. Choose a style when polishing, or set a default style for a work. Styles are saved with full-library backups.
- **Proofreading**　Check a selection or the current chapter for typos, grammar, and punctuation, and accept fixes one by one in the same side-by-side view.
- **Summaries**　Summarize a selection, a chapter, or the whole book. Book summaries remember each chapter’s summary and redo only the chapters that changed, which is faster and costs less; the cache can be cleared in Settings. Keep any summary as an idea.
- **Web pane summaries (desktop)**　The web pane toolbar has a new Summarize button for the selection or the whole page. Keep the result as an idea or turn it into a task, with or without the link. Only the page you chose to summarize is sent, and web panes still keep no history.
- The existing local AI interface (v1) is unchanged.

### Compatibility

The library database moves to v11 (for writing styles) the first time it opens. Projects still use Schema 3 and full-library backups still use format 2; new backups include writing styles, and older backups restore as before. AI profiles, keys, and the chapter summary cache stay on this device and are not included in backups.
