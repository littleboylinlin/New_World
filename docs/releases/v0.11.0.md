## 外观设置与写作工具

- 新增「设置 → 外观」：主题可选跟随系统、白色、黑色、米黄色，作用于整个应用；桌面版窗口直接以所选主题的底色打开。
- 英文字体与中文字体分开选择：Times New Roman（默认）、Georgia、Lora、Inter、系统无衬线；中文可选自动、宋体、黑体、楷体。Lora 与 Inter 随应用附带，离线可用。
- 正文字号、行距、段落间距、首行缩进和正文宽度可调。阅读页和编辑器工具栏的「Aa」按钮可快速切换主题、字号和英文字体。
- 字数统计改为中文按字、英文按词计数，混排相加。
- 新增英文拼写检查（默认关闭），右键可查看建议或加入词典。Windows 版附带美式和英式英语词典，离线可用；也可导入或从 https 链接下载其他语言的 Chromium 词典。
- 新增「专注写作」，只留本章正文，按 `Esc` 退出。
- 导出与打印不受外观设置影响。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Appearance settings and writing tools

- New "Settings → Appearance": Match system, White, Dark or Beige themes for the whole app; the desktop window opens with the chosen theme's background.
- Separate English and Chinese fonts: Times New Roman (default), Georgia, Lora, Inter or System Sans, with Auto, Song, Hei or Kai for Chinese. Lora and Inter ship with the app and work offline.
- Adjustable text size, line spacing, paragraph spacing, first-line indent and text width. The "Aa" button in the reading and editor toolbars switches theme, text size and English font.
- Word counts now count Chinese by character and English by word, adding both in mixed text.
- English spell check (off by default) with suggestions on right click. The Windows app ships US and UK English dictionaries for offline use; other Chromium dictionaries can be imported or downloaded from an https link.
- New "Focus" mode that leaves only the chapter text; press `Esc` to leave.
- Exports and printing are not affected by appearance settings.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
