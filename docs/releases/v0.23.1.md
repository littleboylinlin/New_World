## v0.23.1 更新内容

- **并发下载**　桌面版更新按 4 MiB 分块，默认使用六条连接并发下载，优先走镜像。某块断线或连续 45 秒未收到数据时，只重试这一块，有可用备源就换源。没有可用的分块源时，使用单连接下载整包。
- **断点续传**　退出 New World 后重新打开，再次发起同一更新时会从已保存的分块继续。下载完成后会校验安装包大小和 SHA-256，安装前再复核一次。
- **下载进度**　更新页和横幅显示总进度与当前下载速度。下载期间可以继续写作。

### 兼容性

书库数据库仍为 v10，工程仍使用 Schema 3，全库备份仍使用格式 2。

## What's New in v0.23.1

- **Parallel downloads**　The desktop updater downloads installers in 4 MiB blocks over six connections by default, starting with the mirror. If a block disconnects or receives no data for 45 seconds, the updater retries that block, switching sources when possible. If no source supports range requests, the updater downloads the full installer over one connection.
- **Resuming downloads**　After reopening New World, start the same update again to continue from the blocks already saved. The updater checks the size and SHA-256 of the completed installer and verifies them again before installation.
- **Download progress**　The update page and banner show overall progress and the current download speed. You can keep writing while the update downloads.

### Compatibility

The library database remains at v10, projects still use Schema 3, and full-library backups still use format 2.
