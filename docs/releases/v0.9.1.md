## 界面修复

- Windows 和 macOS 同步修复标题栏布局，解决「本地保存」文字与回收站按钮重叠的问题。
- 根据系统窗口按钮占用后剩余的空间调整标题栏；窄窗口下隐藏辅助文字，保留可操作的回收站和设置入口，避免中英文界面换行或挤入系统按钮。
- 回收站缩为图标时仍保留对应语言的无障碍名称。

本次同时提供 Windows x64 安装包、Apple Silicon 和 Intel 的 macOS DMG。两端检查更新时仍只选择本平台、本机架构的安装包。覆盖安装保留书库和语言选择。

Windows 安装包未做 Authenticode 签名；Mac 安装包采用本地签名，尚未做 Developer ID 签名或公证。下载文件的 SHA-256 校验值见 `SHA256SUMS.txt`。

## Interface fixes

- Fixes the title bar on both Windows and macOS, including the overlap between the local-storage status and Trash.
- Adapts to the space left after native window controls. Narrow windows hide secondary labels while keeping Trash and Settings usable in both languages.
- Keeps a localized accessible name for the icon-only Trash button.

Includes a Windows x64 installer and separate macOS DMGs for Apple Silicon and Intel. Update checks continue to select only the matching platform and architecture. Installing over the existing app preserves books and language preferences.

The Windows installer is not Authenticode signed. The Mac app is ad-hoc signed and is not Developer ID signed or notarized. Verify downloads against `SHA256SUMS.txt`.
