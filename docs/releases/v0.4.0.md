## Windows 桌面版

- 下载 `New-World-Setup-0.4.0-x64.exe` 安装。目标平台为 Windows 11 x64，安装在当前用户下，首次安装不需要 Node.js。
- 两个书库、小说编辑、原件导入和导出均可离线使用。Windows 版可直接选择保存 PDF 的位置。
- 启动时在后台检查更新。「帮助与更新」也可以手动检查、查看说明和下载安装包。安装前请保存稿件并退出 New World。
- 桌面书库保存在 `%APPDATA%\NewWorld`。覆盖安装和正常卸载保留该目录。首次安装时，原先在浏览器写的稿件仍保存在浏览器书库里，桌面版不会自动搬入。

安装包未使用 Authenticode 签名，Windows 可能显示未知发布者提示。可用同页 `SHA256SUMS.txt` 核对安装包的 SHA-256。
