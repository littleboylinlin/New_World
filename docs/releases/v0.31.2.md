## v0.31.2 更新内容

这一版统一并优化了整个界面的动画，操作更快、更跟手。

- **更快、更统一**　所有动画只保留四档时长：悬停和按下 100ms，菜单和提示 150ms，弹窗和面板 200ms，切换页面和章节 260ms。关闭比打开更快，不用再等动画播完。
- **更克制**　页面切换、章节切换、弹窗、菜单和提示的位移都缩小了，弹窗和菜单不再回弹，只有撤销提示和数值变化保留轻微的弹性。列表依次出现时只有前 6 项参与，整体不超过 0.25 秒。
- **更流畅**　侧栏收起展开、分栏、折叠块和章节拖动排序改用更省性能的方式过渡，不再改变元素宽高和位置。快速连续操作时，新动画会直接接上，不会排队。
- **设定画布**　拖动、缩放和平移时不加任何过渡；选中框出现时轻轻淡入，套索收尾更快，去掉了新连线的闪烁。
- **减少动态效果**　系统开启“减少动态效果”时，所有动画仍然直接关闭。

## What's New in v0.31.2

This release unifies and refines motion across the app, so everything feels quicker and more responsive.

- **Faster and consistent** — Every animation now uses one of four durations: 100ms for hover and press, 150ms for menus and tips, 200ms for dialogs and panels, and 260ms for page and chapter changes. Closing is faster than opening, so you never wait for an animation to finish.
- **More restrained** — Page, chapter, dialog, menu and notice movements are smaller, and dialogs and menus no longer bounce. Only the undo toast and value changes keep a light spring. Staggered lists animate only their first six items and finish within 0.25 seconds.
- **Smoother** — Collapsing the sidebar, split panes, collapsible sections and chapter reordering now animate without changing element size or position. Rapid repeated actions pick up where the last animation left off instead of queueing.
- **Story canvas** — Dragging, zooming and panning have no transitions. New selection boxes fade in briefly, the lasso clears faster, and new connections no longer flash.
- **Reduced motion** — When the system's reduce-motion setting is on, all animations are still turned off.
