## 安全与数据可靠性修复补丁

- **回收站长期保留机制**：移除应用启动时自动永久清理超过 30 天回收站记录的逻辑与界面倒计时提示；已删除的作品、原文附件、编辑版本、章节与灵感现在会持续安全保留，直到用户在界面中手动恢复或经过独立二次确认后彻底删除；完全兼容历史版本已有的回收站记录，并继续严格禁止 AI 访问回收站。
- **灵感修改原子历史与章节完整恢复**：AI 调用 `ideas.update` 修改已有灵感（包含正文、使用状态或关联作品）前，在同一严格 IndexedDB 事务中原子写入 `ideaRevisions` 历史快照，快照失败则中止修改；灵感页新增历史版本预览与一键恢复（恢复前自动备份当前状态），继续严格隔离 AI 对灵感历史的访问。同步修复 `restoreChapterRevision()`，在同一事务中同时恢复原章节标题与正文内容，并即时更新目录与编辑区标题。
- **确认状态一致性、权限即时收紧与备份 ZIP 防护**：增强 `works.delete`、`editions.delete`、`chapters.delete`、`sources.delete`、`ideas.delete` 及破坏性 `chapters.update` / `chapters.replaceBatch` 的状态指纹与执行前二次核验，若等待人工确认期间目标发生实质变更则返回 `409 stale_confirmation_target` 拒绝旧确认；权限撤销或访问范围缩小后立即取消受影响的待确认请求。为备份 ZIP 解压增加条目数量、清单体积与累计流式解压字节上限以防御 ZIP 炸弹，同时完整兼容并导出/恢复去重历史数据。
- **历史快照无损去重压缩与 Electron 权限隔离**：使用异步 gzip 压缩与内容寻址 `revisionBlobs` 去重降低章节历史存储占用，新增历史库空间统计、容量预警与需用户明确确认的较早历史清理功能（始终保留至少 1 个最近可恢复版本）。加强桌面端主窗口与快速灵感悬浮窗（`#/capture`）之间的 IPC 发送方隔离，并为应用内安装包更新增加体积上限与 `Content-Length` 核验。

提供 Windows x64、Mac Apple Silicon 和 Intel 安装包。SHA-256 校验值见 `SHA256SUMS.txt`。

## Security & data-reliability patch

- **Indefinite Trash retention (no automatic 30-day purge)**: Removed the 30-day automatic trash expiration and countdown labels. Deleted works, source attachments, editions, chapters, and ideas remain recoverable until manually restored or permanently deleted with an independent second confirmation, while preserving full compatibility with legacy trash entries and strict AI isolation.
- **Atomic pre-edit snapshots for ideas & complete chapter restore**: Added IndexedDB v7 `ideaRevisions` snapshots written atomically inside the same strict transaction as `ideas.update` (aborting updates if snapshot persistence fails), along with in-app idea history preview and restore (backing up current state first) and strict AI isolation. Fixed `restoreChapterRevision()` to restore both original chapter titles and body content in one transaction while refreshing the sidebar and editor heading.
- **Confirmation state integrity & ZIP bomb defenses**: Expanded confirmation fingerprints and execution-time state verification (`409 stale_confirmation_target` if targets change while awaiting approval), immediately cancelled pending confirmations on permission revocation or scope shrinkage, and added streaming entry-count and decompression byte limits (`tooLarge`) to backup restore without breaking legacy or v7 backups.
- **Lossless deduplicated revision storage & Electron IPC hardening**: Added gzip-compressed content-addressed `revisionBlobs` deduplication, storage stats and soft threshold warnings, and user-confirmed older-history pruning that always preserves at least the latest recoverable snapshot. Enforced strict IPC sender separation between the main library window and the quick-capture window, plus updater size bounds and `Content-Length` verification.

Includes Windows x64 and separate Mac Apple Silicon and Intel installers. Verify downloads with `SHA256SUMS.txt`.
