## 修复组字光标与平滑打字

- **组字期间跟随**：中文、日文等输入法组字时，自绘光标读取原生选区的实时位置，不再冻结；只移动覆盖层，不改动输入法选区。
- **多字上屏平滑追赶**：同行输入改用 rAF 逐帧追赶，默认每帧接近目标剩余距离的 35%，小于 0.5px 时贴合并停止循环。移除原来的 CSS 过渡和 80px 距离阈值，一次提交多个字也能平滑移动。
- **跳转直接定位**：鼠标点击、方向键、Home/End、PageUp/Down、查找跳转、撤销重做及跨行移动直接定位。系统开启「减少动态效果」时，输入也直接定位。
- **保留已有行为**：选区和失焦时隐藏，颜色跟随主题；窗口缩放、滚动、字体、图片和表格布局变化后同步。打字机模式、字数防抖和自动保存沿用原有设置。

沿用 v0.20.0 的数据库 v9、工程 Schema 3 和全库备份格式 2，不增加数据迁移。历史版本的升级与回退边界见 [v0.19.0 说明](https://github.com/littleboylinlin/New_World/releases/tag/v0.19.0)。

[功能验收](https://github.com/littleboylinlin/New_World/actions/runs/44109766927)通过浏览器 225 项、Windows 安装版 15 项、macOS arm64/x64 安装版各 8 项测试。轨迹测试覆盖组字更新、多字上屏、停止后不运行 rAF、点击瞬移和减少动态效果；11.5 万字输入测试保留。组字由 Chromium IME 协议覆盖，系统输入法候选窗尚未进行实体机手测。本版安装包以发布流水线的构建、安装回归和附件哈希校验为准。

## IME Caret and Smooth Typing Fixes

- **Follow composition**: During Chinese, Japanese and other IME composition, the overlay follows the native selection's current position instead of freezing. It moves only the overlay, without changing the platform's selection.
- **Smooth multi-character input**: Same-line input now follows its target through requestAnimationFrame, closing 35% of the remaining distance per frame by default. Below 0.5px it reaches the target and stops scheduling frames. The old CSS transition and 80px threshold are removed, so multi-character commits can move smoothly too.
- **Immediate jumps**: Clicks, arrow keys, Home/End, PageUp/Down, search jumps, undo/redo and line changes position the caret immediately. The system's reduced-motion preference also makes input movement immediate.
- **Existing behavior retained**: The caret hides for selections and loss of focus, follows the theme, and resynchronizes after zoom, scrolling, fonts, images or table layout changes. Typewriter mode, deferred counts and autosave keep their existing settings.

Database v9, project Schema 3 and full-library backup format 2 remain as in v0.20.0, without an additional migration. See the [v0.19.0 guidance](https://github.com/littleboylinlin/New_World/releases/tag/v0.19.0) for earlier upgrade and rollback limits.

[Feature validation](https://github.com/littleboylinlin/New_World/actions/runs/44109766927) passed 225 browser tests, 15 Windows installed-app tests and 8 tests for each macOS architecture. Trajectory tests cover composition updates, multi-character input, idle frame scheduling, immediate clicks and reduced motion; the 115,000-character typing test remains. Composition is covered through Chromium's IME protocol; physical system candidate windows were not manually tested. This version's installers are subject to the release workflow's build, installation tests and asset hash checks.
