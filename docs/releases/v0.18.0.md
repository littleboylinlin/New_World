## New_World 原生小说工程格式

- **完整作品工程**：新增 ZIP 容器的 `.newworld` 文件，使用公开、独立版本的 Schema 1。保留作品名称、稳定 ID、所属书库、封面、全部编辑版本及章节顺序、Tiptap 富文本、阅读批注和自定义颜色、原始文件字节、关联灵感、历史版本及必要引用。续写／仿写工程保留原文与续写关系，也包含直接关联附属原文的灵感、灵感历史和本作品回收记录。
- **独立导入导出入口**：作品书架菜单和续写详情提供「导出 New_World 工程（.newworld）」，首页与书库提供工程导入。导入先验证并显示作品、版本、章节及原文件摘要，确认后再写入；检测重复作品、原文件和 ID 冲突，可跳过或导入独立副本。副本同步映射内部引用，导入失败整体回滚，不覆盖已有作品或全库，不复用全库 ZIP 备份恢复。
- **桌面文件关联与可靠保存**：Windows 安装器注册 `.newworld`，macOS 声明专属 UTI。双击文件或在应用已运行时打开文件，均进入导入预览，保留正在编辑的稿件。桌面导出可选择位置和 Unicode 文件名，经同目录临时文件、同步写入、重读校验及原子重命名后保存。
- **严格验证与迁移回归**：检查 SHA-256、UTF-8 JSON、字段类型、引用、ZIP 路径穿越、重复／重叠条目、压缩率、大小与数量，并对历史 gzip 单独限额。提供[验收示例](https://github.com/littleboylinlin/New_World/blob/v0.18.0/docs/examples/雾港.newworld)，已验证原创和续写工程跨干净书库往返、批注实际显示、历史／灵感／回收恢复、副本映射、继续编辑及损坏文件回滚。
- **保留现有格式互通**：继续使用现有 TXT、Markdown、HTML、DOCX、PDF 正文导出器，并说明各格式的保留范围；这些正文格式不携带完整工程专属数据。本轮不新增 EPUB 导出器。

### 兼容性与限制

- 工程 Schema 保持为 **1**，不使用应用版本号代替 Schema；不支持的 Schema 明确拒绝。工程上限为 **512 MiB**，其他资源及安全限制见[正式格式规范](https://github.com/littleboylinlin/New_World/blob/v0.18.0/docs/newworld-format.md)。
- 导入后继续在本地书库编辑，修改**不会自动写回来源工程**，需要重新导出。`.newworld` 是 New_World 工程格式，不面向通用阅读器。
- 本地书库升级至 **IndexedDB v8**，支持具有相同原文件字节的独立副本。旧版 v7 应用不能直接打开升级后的同一书库；升级前可使用现有全库备份保留副本。
- 不包含全局设置、未关联灵感、其他作品、账户凭据、缓存或会话撤销栈。已不存在的历史父记录只保留真实引用，不补造缺失作品、版本或章节。

提供 Windows x64、Mac Apple Silicon（arm64）和 Intel（x64）安装包，以及简体中文、英语语言包。使用同页的 `SHA256SUMS.txt` 校验下载文件。

## Native New_World Novel Projects

- **Complete work projects**: Adds ZIP-based `.newworld` files with a public, independently versioned Schema 1. Retains work names, stable IDs, libraries, covers, every edition and chapter order, Tiptap rich text, reading annotations and custom colors, original source bytes, related ideas, history and required references. Continuation/imitation projects retain source relationships, including ideas, idea history and work trash linked directly to attached source records.
- **Dedicated import and export**: Export from a work's shelf menu or continuation details; import from the home or library page. Files are validated and summarized before confirmation. Duplicate works, sources and identity conflicts can be skipped or imported as independent copies with remapped references. Failed imports roll back entirely, without overwriting existing works or using full-library ZIP backup recovery.
- **Desktop associations and reliable saves**: Windows installers register `.newworld`; macOS declares its own UTI. Opening a file at startup or in a running app shows an import preview while preserving the current manuscript. Desktop exports support location and Unicode filename selection, temporary files, synchronized writes, read-back verification and atomic rename.
- **Strict validation and migration coverage**: Checks SHA-256, UTF-8 JSON, field types, references, ZIP paths, duplicate/overlapping entries, compression ratios, sizes and counts, with separate limits for historical gzip payloads. The [sample project](https://github.com/littleboylinlin/New_World/blob/v0.18.0/docs/examples/雾港.newworld) supports acceptance testing. Coverage includes original and continuation round trips through clean libraries, rendered annotations, history/idea/trash recovery, copy mapping, continued editing and damaged-file rollback.
- **Existing document formats remain available**: Reuses TXT, Markdown, HTML, DOCX and PDF exporters, with explicit descriptions of what each preserves. These manuscript formats do not carry complete project state. This release does not add an EPUB exporter.

### Compatibility and Limitations

- Project Schema remains **1**, separate from the application version. Unsupported schemas are rejected. Projects are limited to **512 MiB**; see the [format specification](https://github.com/littleboylinlin/New_World/blob/v0.18.0/docs/newworld-format.md) for other resource and safety limits.
- Editing continues in the local library. Changes **are not automatically written back** to the source project; export again to save an updated file. `.newworld` is a New_World project format, not a general reader format.
- The local library upgrades to **IndexedDB v8**, allowing independent copies with identical source bytes. Older v7 apps cannot directly open the same upgraded library; use the existing full-library backup before upgrading if you need a copy of the earlier state.
- Global settings, unlinked ideas, unrelated works, credentials, caches and session undo history are excluded. Missing historical parents retain their real references without inventing absent works, editions or chapters.

Includes Windows x64 and separate Mac Apple Silicon (arm64) and Intel (x64) installers, plus Simplified Chinese and English language packs. Verify downloads with `SHA256SUMS.txt` on this release page.
