# 阅读批注

在编辑稿的「阅读模式」或文字原文件预览中框选正文，点击选区旁的「添加批注」。工具栏仅在鼠标释放并形成有效选区后出现，拖动中保持隐藏；也支持键盘选择。批注支持多行内容（最多 10000 字符）、预设色和自定义颜色。保存后立即生效，取消不创建记录。

- **文字标记**：悬停预览，移入卡片可继续阅读；点击文字或卡片固定，点击其他位置、其他标记或按 Escape 收起。重叠范围用分色条纹显示，卡片列出该范围的全部批注。
- **行间批注**：在选区末端附近的现有行间空隙显示小箭头和简短预览，使用小字号、低饱和度文字，背景透明，不增加正文行高、段落或换行。空间不足时截断预览，紧凑行距下可只显示箭头。接近的标记共用入口，悬停或点击后在浮层中列出全部批注；悬停、固定和外部点击收起规则与文字标记一致。每条批注可在编辑对话框切换形式；「阅读批注」列表也支持统一切换本章的形式。
- **管理**：「阅读批注」列表可查看、编辑或删除本章批注，包括已失效的批注。删除只影响批注。批注不增加正文保存次数、字数或历史正文版本。浮层和管理列表仅展示批注内容及轻量编辑、删除入口，不重复展示标题、引文或原文摘录。

行间模式的「行间文字颜色」与文字标记模式的「高亮背景颜色」分别提供预设和自定义颜色选择器。前者只设置批注预览的 CSS `color`，不设置背景色；后者只设置原文高亮。切换形式保留两种配置。

## 数据和定位

`ChapterRecord.readingAnnotations?` 保存编辑稿章节的批注；`ImportedBook.readingAnnotations?` 按原文件的 `text` / EPUB `section:<index>` 保存文字预览批注。集合包含独立的 `revision` 和 `items`；每条记录包含稳定 UUID、正文锚点、内容、颜色、展示形式、折叠状态和创建时间。

`color` 保留原有高亮背景色，新增可选 `inlineColor` 仅保存行间批注字体色。旧记录缺少 `inlineColor` 时使用主题的低饱和度文字色，读取时不重写数据；既有 ID、锚点、高亮色和 `collapsed` 字段均保留，行间显示统一使用轻量预览与临时浮层。

锚点包含版本、正文类型、精确起止位置、原文摘录和 SHA-256 校验值。编辑稿使用 ProseMirror 文档位置，原文件文字使用 UTF-16 位置。章节、版本和作品 ID 隔离不同正文；不通过搜索相同字符串重新定位。重叠范围分段保留全部批注 ID。

校验采用保守策略：只要整章文档发生变化（包括格式）或原文件当前解码文字改变，旧锚点即失效。批注仍可在列表管理，但不会画到正文上；恢复到完全一致的正文后可恢复标记。当前版本不会自动猜测新位置，暂不支持手动重新锚定。

读写与现有 IndexedDB 共用事务，批注保存检查集合版本和源章节版本/原文件摘要，冲突时保留输入并提示取消重开；不静默覆盖其他窗口。正文保存始终合并最新记录，保留已有批注。

这是可选字段的增量扩展：旧记录缺少字段时按空集合读取，首次保存才添加，不改数据库版本、不重写旧正文。现有整库备份和回收站按完整所属记录保存/恢复这些字段；永久删除所属记录时批注随之删除，不增加孤立数据表。

## 兼容范围

支持原创库和续写/仿写库的编辑稿阅读模式，以及现有 TXT、Markdown 源码、HTML 纯文本、RTF、DOCX、ODT、EPUB 文字预览。PDF 当前为画布预览，不能选取真实文字，不接入批注；仅能下载的格式也不接入。图片本身不作为文字选区。

Tiptap 装饰层仅绘制原文高亮；行间标记使用正文之外的覆盖层，按实际文字矩形寻找空隙，并避让正文、其他标记及滚动容器边界。它不向文档树插入数据，也不增加正文的 DOM 文本。选区复制只复制正文。原文件下载及现有 TXT、Markdown、HTML、DOCX、PDF 正文导出流程保持原有行为，当前版本的正文导出不包含批注，暂不提供独立的批注导出格式。

浏览器交互测试覆盖选区/重复文字/跨段落、两种形式、重叠、悬停和固定、编辑删除、颜色、窄窗口、滚动、只读键盘、查找、并发冲突、重开、原文件和 EPUB 分节、回收站、备份与正文导出。Windows 安装版测试覆盖批注管理及应用重启持久化场景。
