# 阅读批注

在编辑稿的「阅读模式」或文字原件预览中框选正文，点击选区旁的「添加批注」。支持多行内容（最多 10000 字符）、五种预设色和自定义颜色。保存后立即生效，取消不创建记录。

- **文字标记**：悬停预览，移入卡片可继续阅读；点击文字或卡片固定，点击其他位置、其他标记、关闭按钮或 Escape 收起。重叠范围用分色条纹显示，卡片列出该范围的全部批注。
- **行间批注**：放在选区结束所在的顶层段落/块之后，文字原件则放在对应换行之后。可展开、收起，不改变正文顺序。每条批注可在编辑对话框切换形式；「阅读批注」列表也支持统一切换本章的形式。
- **管理**：「阅读批注」列表可查看、编辑或删除本章批注，包括已失效的批注。删除只影响批注。批注不增加正文保存次数、字数或历史正文版本。

## 数据和定位

`ChapterRecord.readingAnnotations?` 保存编辑稿章节的批注；`ImportedBook.readingAnnotations?` 按原件的 `text` / EPUB `section:<index>` 保存文字预览批注。集合包含独立的 `revision` 和 `items`；每条记录包含稳定 UUID、正文锚点、内容、颜色、展示形式、折叠状态和创建时间。

锚点包含版本、正文类型、精确起止位置、原文摘录和 SHA-256 校验值。编辑稿使用 ProseMirror 文档位置，原件文字使用 UTF-16 位置。章节、版本和作品 ID 隔离不同正文；不通过搜索相同字符串重新定位。重叠范围分段保留全部批注 ID。

校验采用保守策略：只要整章文档发生变化（包括格式）或原件当前解码文字改变，旧锚点即失效。批注仍可在列表管理，但不会画到正文上；恢复到完全一致的正文后可恢复标记。本轮不自动猜测新位置，也不提供手动重新锚定。

读写与现有 IndexedDB 共用事务，批注保存检查集合版本和源章节版本/原文件摘要，冲突时保留输入并提示取消重开；不静默覆盖其他窗口。正文保存始终合并最新记录，保留已有批注。

这是可选字段的增量扩展：旧记录缺少字段时按空集合读取，首次保存才添加，不改数据库版本、不重写旧正文。现有整库备份和回收站按完整所属记录保存/恢复这些字段；永久删除所属记录时批注随之删除，不增加孤立数据表。

## 兼容范围

支持原创库和续写/仿写库的编辑稿阅读模式，以及现有 TXT、Markdown 源码、HTML 纯文本、RTF、DOCX、ODT、EPUB 文字预览。PDF 当前为画布预览，不能选取真实文字，不接入批注；仅能下载的格式也不接入。图片本身不作为文字选区。

Tiptap 使用装饰层和只读控件展示批注，不向文档树插入数据。选区复制只复制正文。原文件下载及现有 TXT、Markdown、HTML、DOCX、PDF 正文导出流程保持原有行为，不导出批注，也未新增批注导出格式。

浏览器交互测试覆盖选区/重复文字/跨段落、两种形式、重叠、悬停和固定、编辑删除、颜色、窄窗口、滚动、只读键盘、查找、并发冲突、重开、原件和 EPUB 分节、回收站、备份与正文导出。Windows 安装版测试增加批注管理及应用重启持久化场景。
