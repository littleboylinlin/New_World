# New World

New World v0.1.0 是一个中文小说管理器。**原创库**收录自己的小说，**续写／仿写库**收录准备参考的原作。两个书库分别管理，可以批量导入、查看、重命名、删除和下载原文件。

## 运行

需要 Node.js 22.16 或更新版本。使用 Node.js 24 运行 CI。

```sh
npm ci
npm run dev
```

用浏览器打开终端显示的本机地址。生产构建使用 `npm run build`，生成的 `dist/` 可通过 HTTPS 静态托管。用 `npm run preview` 可在本机查看生产构建。

## 文件与预览

| 格式 | 应用内预览 |
| --- | --- |
| TXT | 正文。可手动切换 UTF-8、GB18030／GBK、Big5、UTF-16 LE／BE 和 Windows-1252。 |
| PDF | 按页渲染原页面。加密、损坏或超出预览上限的文件可下载原件。 |
| EPUB | 按书籍目录顺序阅读文本章节。图像、样式与 DRM 内容的完整阅读请使用兼容的阅读器。 |
| DOCX、ODT | 提取正文文本与段落。版式、插图和嵌入对象保留在原件中。 |
| Markdown（`.md`、`.markdown`） | 源文。 |
| HTML（`.html`、`.htm`） | 提取正文文本，禁用脚本及远程资源。 |
| DOC、RTF、MOBI、AZW3 | 保存和下载原文件。 |

单个文件导入上限为 128 MiB。PDF 预览上限为 64 MiB，文本及压缩文档的单个正文部件预览上限为 16 MiB。遇到无法预览的内容，详情页仍可下载原件。重命名只更新书库中显示的作品名。

## 本地数据

应用使用 IndexedDB 保存作品信息与原始文件。数据按浏览器配置和网站地址隔离，重新打开同一个地址仍可访问。切换浏览器、站点或端口会进入另一份书库。浏览器清除站点数据时会一并删除书库。应用导入、解析与阅读均在本地完成。

作品用书库和稳定 ID 标识。元数据与原件在同一事务中写入或删除，按书库和原始文件的 SHA-256 去重。同一文件可以分别存进两个库。

## 开发与验证

Vite 和 TypeScript 提供静态应用。`src/library.ts` 管理本地数据，阅读器按需加载 PDF 和压缩文档解析器。后续人物、章节和设定等模块可引用作品 ID。v0.1.0 的范围是书库管理和文件阅读预览。

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

测试使用生产构建，覆盖两个书库、导入与去重、重命名和删除、关闭浏览器后恢复、中文编码、PDF 翻页、EPUB 章节、DOCX／ODT 文本、异常文件、原件下载和手机视口。测试文件由测试代码生成。若使用已有的 Chromium，可设置 `CHROMIUM_PATH` 指定可执行文件。

PDF.js 和 zip.js 的许可证随构建输出分发。
