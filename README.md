# New World

[English](README.en.md)

New World 是一个本地小说管理器。原创库用于创作和管理自己的小说，续写／仿写库按原作组织续写项目。最新版本见 [GitHub Releases](https://github.com/littleboylinlin/New_World/releases/latest)，各版本的改动见 [发行说明](docs/releases)。

## 平滑写作（v0.20.1）

编辑器光标随当前行字号和主题显示，输入引起的同行移动逐帧平滑追赶；点击、导航、撤销重做及跨行跳转直接定位。选中文字或失去焦点时隐藏；组字期间跟随原生输入位置，不改动输入法选区。窗口缩放、滚动、字体、图片和表格改变布局后会重新同步。

「设置 → 外观 → 打字机模式」默认关闭。开启后，输入和换行时将当前行保持在编辑区中央附近；手动滚动查看时停止跟随，再次输入后恢复。光标移动和居中滚动均遵守系统的「减少动态效果」。

「设置 → 外观 → 平滑光标与打字」默认开启。关闭后正文和所有输入框都使用系统原生光标，切换立即生效，选择保存在本机。

字数、章节大纲和正文搜索结果在停笔约 400ms 后更新，自动保存等待约 500ms；手动保存和离开章节仍立即保存。连续输入期间不再反复扫描全文或生成保存快照，字数显示允许稍微滞后。数据库 v9、工程 Schema 3 和全库备份格式 2 沿用 v0.19.0；详见 [v0.20.1 发行说明](docs/releases/v0.20.1.md)。

## 本地任务工作区（v0.19.0）

v0.19.0 正式提供独立的本地任务管理，无需账号，没有 Todoist 云端同步或账号系统。支持项目/子任务、标签过滤、重复与本地提醒、列表/看板/日历/表格、评论附件、模板统计、任务 JSON 导入导出，以及作品/章节关联和灵感转任务。本地提醒仅在应用运行且渲染活跃时检查；后台可能延迟，完全退出、关闭浏览器或关机后无通知。

**升级前请先在 v0.18.1 中备份并保留备份文件。** 本版将 IndexedDB v8 升至 v9，工程读取 Schema 1/2/3、写入 Schema 3，全库备份写入格式 2、继续读取格式 1。v0.18.1 无法直接打开 v9 数据库，也无法导入 Schema 3 或恢复格式 2 备份；回退须使用升级前备份。单部工程仅包含明确归属该作品的任务，个人任务和本机设置不混入。操作、数据规则、验收测试与限制见 [任务文档](docs/tasks.md)；可用 [Schema 3 创作任务示例](docs/examples/雾港-创作任务.newworld) 验收。下载与升级说明见 [v0.19.0 发行说明](docs/releases/v0.19.0.md)。

## 原生工程格式

书架的作品菜单提供「导出 New_World 工程（.newworld）」，首页和书库提供独立的工程导入入口。工程包含当前作品的全部编辑版本、原始文件、批注、封面及相关历史；导入先校验和预览，冲突可跳过或导入副本，不覆盖已有书库。桌面安装后可双击 `.newworld` 进入导入流程。

导入后仍在本地书库编辑，修改须重新导出，不会自动写回来源工程。现有正文导出继续保留，其格式不携带完整工程状态。详见 [格式规范与限制](docs/newworld-format.md)，可用 [Schema 1 雾港示例工程](docs/examples/雾港.newworld) 验收。v0.18.1 的书库为 IndexedDB v8；v0.19.0 升至 v9，只新增任务表，不重写旧作品。旧版应用不能直接打开升级后的同一书库，回退应使用升级前备份。

## 作品信息（v0.18.1 引入）

v0.18.1 增加原创、续写作品的可选作者、副标题、多段简介、标签及创作状态。新建时可填写，也可从作品菜单或详情的「编辑作品信息」补充、修改和清空；旧作品不填入默认作者或状态。TXT、Markdown、HTML、DOCX、PDF 和 EPUB 导出提供三个默认关闭的作品信息选项，沿用现有正文转换器。

v0.18.1 读取 Schema 1 / 2，重新导出使用 Schema 2，作品信息及符合安全预算的未知 JSON 扩展随工程保留；不支持的结构明确拒绝。旧版 v0.18.0 只读取 Schema 1，无法读取 Schema 2。该版数据库为 v8，无批量迁移；当前分支的格式兼容规则见[未发布版本说明](docs/releases/unreleased.md)。参见 [完整兼容规则](docs/newworld-format.md)、[Schema 2 元数据示例](docs/examples/雾港-作品信息.newworld) 和 [v0.18.1 发行说明](docs/releases/v0.18.1.md)。

## Windows 桌面版

Windows 与 macOS 的当前正式版见 [GitHub Releases 最新版](https://github.com/littleboylinlin/New_World/releases/latest)，两个平台同时发布同一版本；每一版的改动见 [发行说明](docs/releases)。升级与回退前须阅读本页的备份提示。原有完整工程迁移、文件关联、阅读批注及正文导出继续保留。使用方式和限制见 [工程格式规范](docs/newworld-format.md) 和 [阅读批注](docs/reading-annotations.md)，AI 接入协议详见 `AI_INTEGRATION.md`。检查更新时各自只选择本平台的安装包。

在 [GitHub Releases](https://github.com/littleboylinlin/New_World/releases) 下载对应版本的 `New-World-Setup-<版本>-x64.exe`。目标平台为 Windows 11 x64，安装到当前用户，无需 Node.js。当前安装包未做 Authenticode 签名，Windows 可能提示未知发布者。可用 PowerShell 的 `Get-FileHash <安装包> -Algorithm SHA256` 与同页 `SHA256SUMS.txt` 核对。

安装向导可选择新建或空的安装目录。升级时默认沿用已有安装位置。完成页显示实际路径，可勾选「创建桌面快捷方式」和「启动 New World」。开始菜单始终提供入口。

两个书库、编辑和导出均可离线使用。桌面数据默认保存在 `%APPDATA%\NewWorld`，覆盖安装与正常卸载保留该目录。在左下角的「设置」中可更改书库存储位置，也可选择关闭窗口时完全退出或留在后台。页脚显示当前存储位置。

独立设置页按「常规、外观、快捷记录、存储、备份与恢复、AI 接入、更新与关于」分类展示各项本机与更新设置。Web 版会说明关闭方式和存储位置由浏览器管理。

## macOS 桌面版

支持 macOS 13 Ventura 及更新版本，分别提供 Apple Silicon（arm64）和 Intel（x64）的 DMG。在 [GitHub Releases](https://github.com/littleboylinlin/New_World/releases) 下载匹配芯片的 `New-World-<版本>-macos-arm64.dmg` 或 `New-World-<版本>-macos-x64.dmg`，打开后将 New World 拖入 Applications。

应用使用本地签名，尚未使用 Apple Developer ID 签名或公证，首次启动时 macOS 可能要求确认来源。可用 `shasum -a 256 <安装包>` 与同一发行版的 `SHA256SUMS.txt` 核对。

书库默认保存在 `~/Library/Application Support/NewWorld`，语言选择和缓存保存在 `~/Library/Application Support/NewWorld-languages`。替换或删除应用不会删除书库。首次打开时按系统语言只获取对应语言包，此后可离线使用。

标题栏为红黄绿窗口按钮留出空间。应用菜单的「设置」可用 `⌘ + ,` 打开，编辑和保存使用 `⌘` 快捷键。关闭方式、存储位置和中英文切换均在同一设置页面内；选择「留后台」后可从菜单栏图标或 Dock 重新打开。

Mac 检查更新只匹配本机芯片的 DMG。点击「更新并重启」后，下载和校验在应用缓存中完成，期间可以继续写作。应用会准备完整的新应用和所选语言包，保存正文并退出后原子交换整包，新版界面正常打开后才删除旧包；启动失败会恢复旧版。安装位置需要可写，不能直接从只读 DMG 中更新。Windows 安装包和其他芯片的 DMG 都不会触发 Mac 更新。

从 v0.9.x 升级的 Mac 用户仍按旧版流程下载 DMG 并选择替换原应用一次，此后的更新使用整包替换。手动保存的安装包保留。

## 界面语言

支持简体中文和英语。Windows 安装包内置中英文语言包（v0.27.1 起），Mac 首次打开时按系统界面语言从国内镜像（失败时回退 GitHub）只下载一种语言包：中文系统使用简体中文，其他系统使用英语。语言包也会独立发布，应用和安装器会验证大小和 SHA-256；下载失败可重试，验证通过后才继续。

在「设置 → 常规」选择语言并应用。应用会先保存正文，再获取尚未下载的语言包；下载失败时保留当前语言。已下载的语言可离线使用，重新打开应用和升级时沿用已选语言。作品名、章节名和正文不会随界面语言改变。Web 版首次按浏览器语言选择，只请求当前所需的语言包。

语言偏好和桌面语言缓存保存在 `%APPDATA%\NewWorld-languages`，不受书库存储位置变更影响。正常卸载保留缓存。离线准备语言包可放到 `%APPDATA%\NewWorld-languages\packs\0.30.0\zh-CN.json` 或 `en.json`；校验通过后会直接使用。

窗口顶部的应用栏同时是标题栏，可以拖动窗口；右上角的最小化、最大化／还原和关闭按钮由应用自绘，悬停不显示系统提示。缩放用 `Ctrl` 加 `+`、`-`、`0`，全屏用 `F11`；全屏时右上角换成「退出全屏」和关闭两个按钮，macOS 全屏时应用栏收回红绿灯的位置。桌面书库与浏览器书库分开保存，现有浏览器数据仍可在原浏览器和地址中访问。

## 外观

「设置 → 外观」可以选择主题、英文字体、中文字体和正文字号，改动立即生效。阅读页和编辑器工具栏的「Aa」按钮打开一个小面板，可以直接切换主题、调整字号和英文字体，「更多设置…」进入完整设置。

- 主题：跟随系统、白色、黑色、米黄色、柔纸（v0.28.0 引入），作用于整个应用。默认跟随系统的深浅色。顶栏同时是窗口标题栏，在各主题下保持深色。
- 英文字体：Times New Roman（默认）、Georgia、Lora、Inter、系统无衬线。Lora 和 Inter 随应用打包，可离线使用，许可证见 `src/fonts/` 和构建产物中的 `licenses/`。
- 中文字体：自动（默认，英文为衬线字体时配宋体，否则配黑体）、宋体、黑体、楷体，使用系统自带字体。英文字体不含汉字时，汉字由所选中文字体显示。
- 正文字号：阅读和编辑共用，14 到 28 px，可恢复默认。
- 排版：行距（紧凑、标准、宽松）、段落间距（无、标准、宽）、首行缩进两字、正文宽度（窄、标准、宽）。
- 拼写检查：默认关闭，打开后只检查正文的英文拼写，标题和输入框不检查。右键点击标出的单词可选择建议或加入词典。Windows 版附带美式和英式英语词典，离线可用、不联网下载，也可以在设置里导入其他语言的 Chromium `.bdic` 词典，或填写词典文件的 https 链接下载（文件名需与 Electron 的 `hunspell_dictionaries.zip` 中一致，例如 `fr-FR-3-0.bdic`），链接本身必须是 https，下载途中若被跳转到 http 仍可完成但会提示确认来源；添加的词典与内置词典一起使用，可随时移除并立即删除文件；macOS 使用系统拼写检查；Web 版使用浏览器自带的拼写检查。

外观保存在本机。桌面版随书库存储位置一起迁移，并把所选主题另存在 `NewWorld-appearance.json`，使窗口一打开就是对应的底色，不会先闪一下浅色。导出的 DOCX、PDF 和打印始终使用白纸黑字和导出样式中的字体；EPUB 的字体和配色由阅读器决定。

## 运行

需要 Node.js 22.16 或更新版本。使用 Node.js 24 运行 CI。

```sh
npm ci
npm run dev
```

用浏览器打开终端显示的本机地址。`npm run build` 生成可通过 HTTPS 托管的静态站点，`npm run preview` 在本机运行生产构建。

## 版本更新

每次启动时，应用在后台向本仓库的 GitHub Releases 检查一次。界面上的运行版本来自构建时的 `package.json`。检查按 SemVer 比较，普通提交、单独创建的 Git 标签、草稿和预发布版都不会触发更新通知。没有更新或网络异常时，书库照常打开。

在「设置 → 更新与关于」中可手动检查、查看版本号和更新说明。发现新版时显示非弹窗提示，可在本次运行期间忽略同一版本；「查看更新」会直接打开设置中的更新说明。

- 桌面版先读取 `https://dl.writenewworld.com/latest.json`（正式版发布时同步到 R2 的镜像），读不到或没有本平台安装包时才查询 GitHub API。下载时同时从 GitHub 和镜像开始，先收到 1 MB 的一方继续、另一方中止；下载完一律按 latest.json 的大小和 SHA-256 校验，失败或中断就换另一个源重下，两边都失败才报错。
- Windows 版从最近 100 条 GitHub Releases 中选取带 SHA-256 校验值的 Windows x64 正式安装包。点「更新并重启」后，应用内会显示下载进度。下载时可继续写作。安装包校验通过后，应用保存正文、关闭窗口并覆盖原安装目录，安装完成后自动启动。
- 如果正文保存失败，窗口会保留，保存或另存后可继续更新。v0.6.0 及更早版本需先手动覆盖安装一次 v0.7.0 或更新版本。
- Web 版不请求 GitHub。打开页面和切回标签页时，静默比对站点随构建发布的 `version.json`；网站部署了新版时，角落会出现「新版本已就绪」，点击后先确认正文已保存再刷新。
- Web 版数据保存在浏览器里：启动时申请持久化存储（结果见「设置 → 存储」）；Chrome / Edge 可在同一页选择本地文件夹，每部作品以 `.newworld` 文件随自动保存写入，重新选择该文件夹可读回浏览器里没有的作品；超过 7 天未导出时提醒一次，可一键下载或关闭提醒。长期写作建议使用桌面版。

正常更新后，Windows 安装器移除旧程序文件；两端回收应用管理的更新下载缓存，并在新版界面正常打开后清理较早版本的语言包。版本变化时还会刷新旧的页面和编译缓存，不清除 IndexedDB 书库。Mac 也会清理默认下载目录中可识别的旧版中断下载文件。系统占用导致暂时无法删除的文件会重试，仍失败则保留到后续启动处理。书库、设置、当前版本语言包、手动保存的安装包及未知文件均保留。

检查只匿名获取公开版本元数据。小说、原文件和编辑稿均留在本机。

## 阅读和编辑

原创库的作品页可在**原文件**与各个**编辑版本**之间切换。可转换的原件用「转换为编辑稿」创建一份独立正文，PDF 使用「提取文字为编辑稿」。任何格式的作品都可以另建空白编辑稿。「另存为独立版本」可复制当前章节和正文，方便尝试另一种写法。

在续写／仿写库导入原作后，每部原作会有一个项目。项目的「续写列表」可以新建、打开独立续写稿，「原文列表」可以阅读、下载和补充同一原作的文件。需要时可从原文阅读页选择「以原文为底稿续写」。旧版已导入的原作及编辑稿会直接显示在对应列表，原先单独创建的稿件也可在其项目中添加原文。

- 章节目录支持新建、重命名、上下移动、切换和确认删除，并显示每章字数。正文上方显示本章和全书字数。本章标题可用于跳转，字数与文字处理软件的中文字数一致：每个汉字和中文标点算 1，英文等以空格分词的语言每个单词算 1，中英混排时分别计算后相加。
- 编辑器提供段落、标题、加粗、斜体、下划线、列表、引用、分隔线和本地插图。支持浏览器原生选区、剪贴板和中文输入法。
- `Ctrl / ⌘ + S` 保存，`Ctrl / ⌘ + F` 查找本章，`Ctrl / ⌘ + B/I/U` 切换行内样式，`Ctrl / ⌘ + Z` 撤销，`Ctrl / ⌘ + Shift + Z` 重做。查找按字面匹配，可逐处或全部替换。撤销记录属于当前章节编辑会话。
- 「阅读模式」保留目录与查找，编辑操作可通过「编辑正文」恢复。手机宽度下可展开章节目录，工具栏可横向滚动。
- 阅读模式和文字原件预览支持框选正文后「添加批注」，可在行间批注与文字颜色标记之间切换。支持悬停预览、点击固定、多行编辑、删除和重开持久化；重叠范围保留全部批注。PDF 画布预览暂不支持；原文或格式变化会使旧锚点失效并显示提示。详见 [阅读批注](docs/reading-annotations.md)。
- 「专注写作」隐藏目录、页眉以外的按钮和页脚，只留本章正文，工具栏淡化、指向时再显示。按 `Esc` 或再点一次退出，离开页面时自动退出。
- 右键点击章节目录中的章节，可新建、重命名、上下移动或删除章节。
- 页面跳转、章节切换、弹窗和提示带有过渡动画。系统开启「减少动态效果」时不播放动画。

## 作品卡片

书库中的作品卡片上方是封面，下方是书名。点击书名旁的箭头或右键点击卡片，可以打开、重命名、更换封面、归档或删除作品。

- 默认封面按书名生成。「更换封面…」可以上传 PNG、JPEG、WebP、GIF、AVIF 或 BMP 图片（最大 32 MB），原图保存在本地，不压缩；「恢复默认封面」换回默认封面。
- 自定义封面随备份一起保存和恢复。

## 灵感速记

想到什么可以马上记下来，之后在写作时取用。

- 桌面版：在任何地方按全局快捷键（默认 `Ctrl + Alt + N`，Mac 为 `⌃⌥N`）弹出小窗，`Enter` 保存，`Shift + Enter` 换行，`Esc` 关闭。快捷键可在「设置 → 快捷记录」改为 `Ctrl + Shift + Space`、`Alt + Shift + N` 或关闭；被其他程序占用时会提示。也可以从托盘菜单、Windows 任务栏图标的右键菜单或 Mac 的 Dock 菜单打开。
- Web 版：在 New World 页面里按 `Ctrl + Alt + N` 打开记灵感的弹窗。
- 灵感默认关联最近打开的作品，也可以不关联。首页的「灵感」列出全部灵感，未用的排在前面，可以标记已用、改关联作品、复制或删除（可撤销）。
- 编辑器左侧章节目录下方是「这部作品的灵感」，和目录一起固定在侧边，正文写到哪里都能看到。点「插入」把灵感放到光标处并标记为已用，也可以直接记一条新的；工具栏的「灵感」按钮显示未用数量，并可展开或收起。
- 桌面版选中文字后右键可「存为灵感」。灵感随备份一起保存和恢复。

## 桌面菜单

- 托盘菜单：记灵感、新建小说、最近的作品（最多 5 部）、灵感、立即备份、打开备份文件夹、设置、显示和完全退出。
- 文字右键菜单：拼写建议和加入词典、剪切、复制、粘贴、全选，以及「存为灵感」。

## 写作统计

首页在书库列表下方显示写作统计：一张按天记录字数的热力图，加上连续写作天数和总字数两张卡片。

首页的「提醒与待办」列出已逾期、今天和接下来 7 天到期或有提醒的待办，最多 8 条，更多的可从「查看全部」进入任务页。勾选即可完成（可撤销）；点关联作品的待办直接打开那一章那一处，没有关联作品的打开待办详情。窗口足够宽时这张卡片单独占右侧一栏。「最近项目」可在列表和封面两种显示方式之间切换，选择保存在本机。

- 热力图覆盖最近一年，每个方格代表一天，颜色越深表示当天写得越多。光标移到方格上或用方向键聚焦，会显示当天日期和字数；没有写作的日子显示「没有写作」，今天单独标出。
- 字数口径与编辑器一致：每个汉字和中文标点算 1，英文等以空格分词的语言每个单词算 1。只有保存后字数增加才累加当天记录，删改文字不会倒扣。
- 连续写作天数从今天（今天还没写则从昨天）往前数连续有写作的天数；总字数是当前书库全部章节的字数合计。
- 写作天数是单独保存的全局历史，删除作品或清空回收站都不会抹掉它。手机宽度下热力图可横向滚动，配色跟随白、黑、米黄主题，系统开启「减少动态效果」时不播放动画。

## 回收站

删除作品、续写项目的原文、编辑版本或章节时，内容会移入回收站。删除后页面底部的提示可以直接撤销。顶栏的「回收站」列出已删除的内容，可恢复到原来的位置或彻底删除，也可以一次清空。

- 回收站内容默认持续保留，不会自动过期删除，直到用户手动恢复或经二次确认后彻底删除。回收站里的内容仍占用本地存储空间。
- 恢复章节时回到原来的顺序。恢复编辑版本遇到同名版本时，会在名称后加上「恢复」。
- 所属的作品或版本已删除时，需要先恢复它。删除后又导入了相同的原文件时，需要先删除新导入的那一份。

## 归档

书库中每部作品的卡片菜单里都有「归档」。归档的作品不在原创库、续写／仿写库和首页计数中出现，内容保持不变，页面底部的提示可以直接撤销。首页的「归档」和各书库列表旁的「查看归档」列出全部归档作品，可以打开、编辑和导出，也可以「取消归档」放回原来的书库，或删除到回收站。

## 版本历史

从 v0.15.1 起，AI 改稿前和恢复旧版本前都会在同一严格 IndexedDB 事务中自动保留修改前的完整章节或灵感快照（`revisions`、去重压缩的 `revisionBlobs` 及 `ideaRevisions`），并记录持久化的 AI 防累计损失基线（`aiBaselines`），避免跨多次小改或重启逐渐损失原文。

- 在编辑器「⋯ → 历史版本」和灵感页可以浏览历史快照、对比并无损恢复到旧版，也可经确认后清理较早的历史版本。
- 回收站永久删除作品或清空回收站时，会按引用计数安全清理不再被引用的历史记录与基线。

## AI 辅助与本地接入

- **内置 AI 服务（v0.27.0）**：在「设置 → AI 接入」连接你自己的 API（支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini），可保存多套配置并分别指定润色、提问、校对和总结所使用的配置，支持导入导出（不含密钥）。桌面版密钥经系统钥匙串加密保存，Web 版默认不保存密钥（可按设备勾选记住）；所有请求只发往你自己配置的地址，首次发送前会弹窗确认。
- **编辑器与网页块辅助**：选中正文可进行润色、改写、扩写、缩写、改语气或自由提问；支持选区与全章校对，以及选区、单章与全书总结（全书总结按章缓存摘要，只重跑改过的章节）。润色、改写和校对结果支持逐处对照采用或整段采用，采用前自动保存历史快照并支持撤销。桌面版的网页块也支持总结选中内容或整页并存为灵感或待办。
- **写作风格库**：可创建、编辑、导入导出写作风格，或基于自己的章节总结文风，并给作品指定默认风格（v0.27.0）。
- **本地 AI 接口（`v1`）**：桌面版可在「设置 → AI 接入」开启仅本机回环访问的 HTTP JSON 接口（默认关闭），为外部工具提供独立 Bearer 令牌、细粒度读写改删权限与作品范围控制，删除和大幅删减强制在窗口内手动确认并记录本地审计日志；详见 `AI_INTEGRATION.md`。

## 故事设定库

从编辑器顶栏的「设定」打开本书的卡片库。可以按角色、地点、势力、物品和世界规则分类，按名称或别名搜索，也可以从模板开始。卡片支持章节关联、从指定章节起生效的状态和命名关系，删除后可从回收站恢复。桌面版打开独立窗口，Web 版打开新标签页。

## 备份与恢复

「设置 → 备份与恢复」把两个书库、全部编辑稿、原文件、自定义封面、回收站、灵感、设定卡片、写作统计、章节与灵感历史版本、写作风格、AI 防丢基线（`aiBaselines`）以及全部任务数据（含项目、标签、模板、过滤器、完成历史及附件）打包成一个 `.zip` 文件。

- 立即备份：桌面版保存到备份文件夹，Web 版下载备份文件。
- 自动备份（桌面版）：每天（默认）、每周或关闭。到期后在应用打开期间自动进行，保留最近 10 份，手动备份和恢复前的备份不会被自动删除。
- 备份位置（桌面版）：默认为「文稿」下的 `New World Backups`，可以选择其他文件夹，也可以恢复默认位置或直接打开该文件夹。
- 加密：可以不加密，也可以用密码加密（AES-256，可用 7-Zip 等工具打开）。桌面版的密码经系统钥匙串加密后保存，自动备份也会加密；Web 版每次备份时输入密码。忘记密码将无法恢复加密备份。
- 从备份恢复：选择备份文件，加密的备份需要输入密码。确认后用备份替换当前书库，全部写入成功才生效。桌面版替换前会先把当前书库备份到备份文件夹（`New-World-before-restore-…zip`）。
- v0.30.0 写入备份格式 3，把 AI 防丢基线（`aiBaselines`）也打进备份，恢复时一起写回；继续读取格式 1 和格式 2（读取格式 1 时保留当前任务数据；读取不含 `aiBaselines` 的格式 1 或格式 2 旧备份时，会把本机基线清空，不会把对不上的旧基线关联到恢复出来的内容上）。旧版应用拒绝格式 3；如需回退须保留升级前备份。
- 当前分支写入备份格式 4，读取格式 1–4。格式变更及回退说明见[未发布版本说明](docs/releases/unreleased.md)。
- 外观、语言、存储位置，以及 AI 服务配置、API 密钥和章节摘要缓存等本机数据不在备份内。

## 格式能力

「编辑」指原件可转换为独立编辑稿。「导出」指编辑稿可生成该格式的新文件。原件下载是独立操作，会保留导入时的文件名和字节。

导出时可以勾选章节并预览首个所选章节。PDF、DOCX 和 HTML 默认使用白底黑字的标准样式，也可以切换到紧凑或宽松。TXT 保留段落间距，Markdown 保留标题、列表等标记，两种格式都能预览文本。EPUB 导出为 EPUB 3（一章一个文件，带封面、本地插图、书名/作者/语言/唯一标识符及兼容旧阅读器的 `toc.ncx`），字体和配色由阅读器决定。

| 格式 | 导入原件 | 原件预览 | 转换为编辑稿 | 导出编辑稿 | 已知限制 |
| --- | --- | --- | --- | --- | --- |
| TXT | 是 | 正文 | 是 | UTF-8 TXT | 可手动切换 UTF-8、GB18030／GBK、Big5、UTF-16 LE／BE 和 Windows-1252。长段落会分章，导出将富文本和图片简化为文字。 |
| Markdown | 是 | 源文 | 是 | Markdown | 保留常用标题、列表、引用和样式。导出时下划线、图片和复杂表格会简化。 |
| HTML | 是 | 正文文本 | 是 | 独立 HTML | 转换常用结构和内嵌光栅图，剔除脚本、网页样式和远程资源。 |
| RTF | 是 | 正文文本 | 部分 | — | 支持正文、Unicode 与常见 ANSI 编码、基础行内样式。图片、复杂列表和表格留在原件。 |
| DOCX | 是 | 正文文本 | 是 | DOCX | 常用文字样式、标题、列表、表格与可解码内嵌图。分页、脚注、页眉页脚、修订和复杂布局可能简化。 |
| DOC | 是 | — | — | — | 保存及下载旧版 Word 原件。 |
| ODT | 是 | 正文文本 | 部分 | — | 可提取标题、段落、基本列表、表格、常见样式与包内图。页式布局、重复单元格和复杂样式可能简化。 |
| EPUB | 是 | 按阅读顺序显示正文 | 部分 | EPUB 3（含 `toc.ncx`） | 导入转换章节、常见样式和包内图，固定版式、外部资源和 DRM 内容留在原件；导出按章生成电子书，携带元数据、封面与本地插图。 |
| PDF | 是 | 逐页渲染 | 部分 | 桌面版直接保存 PDF，Web 通过打印另存 | 提取可读文字，顺序可能需要调整。扫描件需先做 OCR，加密件需先解锁。导出会重新分页。 |
| MOBI、AZW3 | 是 | — | — | — | 保存及下载电子书原件。 |

单文件导入上限 128 MiB，PDF 预览和转换上限 64 MiB，常规文本及压缩文档单个正文部件上限 16 MiB，RTF 上限 8 MiB。单张内嵌 PNG、JPEG、GIF 或 WebP 图片上限 4 MiB，转换的图片总量上限 24 MiB。转换过大的书籍或损坏、加密的文件时，应用会提示限制并保留原件。

## 保存与隐私

正文停止变更约 500 毫秒后自动保存，切换章节或返回书库前也会尝试保存。保存状态可见。保存失败（例如存储空间不足）时保留上次已提交内容和当前内存中的改动，并在横幅直接提供「重试」和「导出本章」两个主要操作，将「放弃本章未保存改动」降为需要二次确认的次要操作。不同页面同时改同一章会提示冲突，可另存为独立版本。浏览器或设备强制退出时，尚未提交的输入可能需要重新录入。

当前分支使用 IndexedDB v12 存储设定卡片及其回收记录（v0.19.0 在 v9 新增任务表，v0.21.0 在 v10 为回收站删除时间新增索引，v0.27.0 在 v11 新增写作风格表）。以下为历史升级规则：IndexedDB v4 在作品、文件、编辑版本、章节和回收站表旁新增全局写作天数表 `writingDays`，v3 老库打开时自动升级。回收站表自 v3 引入，升级后的书库需要用 v0.5.0 或更新版本打开。两库按复合键隔离，原文件按库进行 SHA-256 去重。编辑稿和原件分别存取，删除作品时在同一事务中把本地副本、编辑版本、章节和设定卡片移入回收站。桌面版使用固定本机目录与应用地址，Web 数据按浏览器配置与网站地址隔离。清除浏览器站点数据会一并删除该浏览器的书库。

导入、转换、编辑和导出均在本地完成。插图保存在编辑稿中，HTML 导入及富文本粘贴会移除可执行内容与远程地址。

## 工程与验证

使用 Vite、TypeScript 和 Tiptap／ProseMirror。编辑器采用与源格式独立的结构化章节模型，格式转换、持久化和导出分别在 `src/documents/` 下维护。构建产物包含第三方许可证与归属文件。

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

Playwright 使用生产构建，覆盖旧库迁移、格式转换与原件校验、章节管理、IME 组合输入、复制粘贴、保存失败、并发冲突、重开恢复和手机视口。CI 保存公开测试样本的截图及导出文件。已有 Chromium 可用 `CHROMIUM_PATH` 指定其可执行文件。

更新检查测试通过拦截 GitHub 接口注入可控的正式版、预发布版和故障响应。运行时读取实际 GitHub Releases 接口。

桌面版使用 Electron 打开相同的生产构建。在 Windows 运行 `npm run desktop` 可启动开发构建，`npm run build:windows` 生成 `dist-windows/` 内的 x64 NSIS 安装包。CI 在 Windows 运行实际安装包，验证离线读写、PDF 导出、应用内更新、原目录覆盖及重启后数据保留。Mac 使用 `npm run build:macos` 和 `npm run test:macos`，在 Apple Silicon 与 Intel 原生 runner 上从 DMG 安装并验证。

发布新版时，在 `release.json` 明确指定版本与 `windows`、`macos` 目标平台；Mac 专用发布不上传 Windows 安装包。在同一 PR 更新 `package.json` 与锁文件的版本，新增 `docs/releases/v<版本>.md`。合并到 `main` 后，CI 在 Web、Windows 和两种 Mac 芯片的检查均通过时生成正式 Release，上传安装包和 SHA-256 校验文件。也可以在 `main` 上手动运行 Checks，填写匹配的正式版本标签重试发布。发布前会校验产物清单，拒绝与目标平台不符的文件。

界面文案集中在 `locales/zh-CN.json` 和 `locales/en.json`。构建时检查两者的键与插值参数，并生成独立语言包和校验清单。桌面安装包包含校验清单，不包含语言包；Release 同时提供两个语言文件，安装器和应用只取得所选语言。修改文案后应更新两个源文件并随新版一起发布。
