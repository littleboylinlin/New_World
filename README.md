# New World

[English](README.en.md)

New World v0.10.4 是一个本地小说管理器。原创库用于创作和管理自己的小说，续写／仿写库按原作组织续写项目。

## Windows 桌面版

Windows 与 macOS 当前正式版均为 [v0.10.4](https://github.com/littleboylinlin/New_World/releases/tag/v0.10.4)。界面控件不再随拖动框选，正文、输入框和文本预览仍可选择复制，顶栏仅保留 New World 品牌名称。检查更新时各自只选择本平台的安装包。

在 [GitHub Releases](https://github.com/littleboylinlin/New_World/releases) 下载对应版本的 `New-World-Setup-<版本>-x64.exe`。目标平台为 Windows 11 x64，安装到当前用户，无需 Node.js。当前安装包未做 Authenticode 签名，Windows 可能提示未知发布者。可用 PowerShell 的 `Get-FileHash <安装包> -Algorithm SHA256` 与同页 `SHA256SUMS.txt` 核对。

安装向导可选择新建或空的安装目录。升级时默认沿用已有安装位置。完成页显示实际路径，可勾选「创建桌面快捷方式」和「启动 New World」。开始菜单始终提供入口。

两个书库、编辑和导出均可离线使用。桌面数据默认保存在 `%APPDATA%\NewWorld`，覆盖安装与正常卸载保留该目录。在顶栏的「设置」中可更改书库存储位置，也可选择关闭窗口时完全退出或留在后台。页脚显示当前存储位置。

「设置」统一列出语言、关闭窗口时、存储位置、帮助与更新。Web 版会说明关闭方式和存储位置由浏览器管理。

## macOS 桌面版

支持 macOS 13 Ventura 及更新版本，分别提供 Apple Silicon（arm64）和 Intel（x64）的 DMG。在 [GitHub Releases](https://github.com/littleboylinlin/New_World/releases) 下载匹配芯片的 `New-World-<版本>-macos-arm64.dmg` 或 `New-World-<版本>-macos-x64.dmg`，打开后将 New World 拖入 Applications。

应用使用本地签名，尚未使用 Apple Developer ID 签名或公证，首次启动时 macOS 可能要求确认来源。可用 `shasum -a 256 <安装包>` 与同一发行版的 `SHA256SUMS.txt` 核对。

书库默认保存在 `~/Library/Application Support/NewWorld`，语言选择和缓存保存在 `~/Library/Application Support/NewWorld-languages`。替换或删除应用不会删除书库。首次打开时按系统语言只获取对应语言包，此后可离线使用。

标题栏为红黄绿窗口按钮留出空间。应用菜单的「设置」可用 `⌘ + ,` 打开，编辑和保存使用 `⌘` 快捷键。关闭方式、存储位置和中英文切换均在同一设置列表中；选择「留后台」后可从菜单栏图标或 Dock 重新打开。

Mac 检查更新只匹配本机芯片的 DMG。点击「更新并重启」后，下载和校验在应用缓存中完成，期间可以继续写作。应用会准备完整的新应用和所选语言包，保存正文并退出后原子交换整包，新版界面正常打开后才删除旧包；启动失败会恢复旧版。安装位置需要可写，不能直接从只读 DMG 中更新。Windows 安装包和其他芯片的 DMG 都不会触发 Mac 更新。

从 v0.9.x 升级的 Mac 用户仍按旧版流程下载 DMG 并选择替换原应用一次，此后的更新使用整包替换。手动保存的安装包保留。

## 界面语言

支持简体中文和英语。Windows 首次安装、Mac 首次打开时需要联网，按系统界面语言只下载一种语言包：中文系统使用简体中文，其他系统使用英语。语言包独立于安装包发布，安装器会验证大小和 SHA-256；下载失败可重试，验证通过后才继续安装。

在「设置 → 语言」选择语言并应用。应用会先保存正文，再获取尚未下载的语言包；下载失败时保留当前语言。已下载的语言可离线使用，重新打开应用和升级时沿用已选语言。作品名、章节名和正文不会随界面语言改变。Web 版首次按浏览器语言选择，只请求当前所需的语言包。

语言偏好和桌面语言缓存保存在 `%APPDATA%\NewWorld-languages`，不受书库存储位置变更影响。正常卸载保留缓存。首次离线安装可将同一发行版的所需语言包放到 `%APPDATA%\NewWorld-languages\packs\0.10.4\zh-CN.json` 或 `en.json`；校验通过后安装器会直接使用。

窗口顶部的应用栏同时是标题栏，可以拖动窗口。缩放用 `Ctrl` 加 `+`、`-`、`0`，全屏用 `F11`。桌面书库与浏览器书库分开保存，现有浏览器数据仍可在原浏览器和地址中访问。

## 外观

「设置 → 外观」可以选择主题、英文字体、中文字体和正文字号，改动立即生效。阅读页和编辑器工具栏的「Aa」按钮打开一个小面板，可以直接切换主题、调整字号和英文字体，「更多设置…」进入完整设置。

- 主题：跟随系统、白色、黑色、米黄色，作用于整个应用。默认跟随系统的深浅色。顶栏同时是窗口标题栏，在各主题下保持深色。
- 英文字体：Times New Roman（默认）、Georgia、Lora、Inter、系统无衬线。Lora 和 Inter 随应用打包，可离线使用，许可证见 `src/fonts/` 和构建产物中的 `licenses/`。
- 中文字体：自动（默认，英文为衬线字体时配宋体，否则配黑体）、宋体、黑体、楷体，使用系统自带字体。英文字体不含汉字时，汉字由所选中文字体显示。
- 正文字号：阅读和编辑共用，14 到 28 px，可恢复默认。
- 排版：行距（紧凑、标准、宽松）、段落间距（无、标准、宽）、首行缩进两字、正文宽度（窄、标准、宽）。
- 拼写检查：默认关闭，打开后只检查正文的英文拼写，标题和输入框不检查。右键点击标出的单词可选择建议或加入词典。Windows 版附带美式和英式英语词典，离线可用、不联网下载，也可以在设置里导入其他语言的 Chromium `.bdic` 词典，或填写词典文件的 https 链接下载（文件名需与 Electron 的 `hunspell_dictionaries.zip` 中一致，例如 `fr-FR-3-0.bdic`；Chromium 官方词典地址形如 `https://redirector.gvt1.com/edgedl/chrome/dict/fr-fr-3-0.bdic`），添加的词典与内置词典一起使用、可随时移除；macOS 使用系统拼写检查；Web 版使用浏览器自带的拼写检查。

外观保存在本机。桌面版随书库存储位置一起迁移，并把所选主题另存在 `NewWorld-appearance.json`，使窗口一打开就是对应的底色，不会先闪一下浅色。导出的 DOCX、PDF 和打印始终使用白纸黑字和导出样式中的字体。

## 运行

需要 Node.js 22.16 或更新版本。使用 Node.js 24 运行 CI。

```sh
npm ci
npm run dev
```

用浏览器打开终端显示的本机地址。`npm run build` 生成可通过 HTTPS 托管的静态站点，`npm run preview` 在本机运行生产构建。

## 版本更新

每次启动时，应用在后台向本仓库的 GitHub Releases 检查一次。界面上的运行版本来自构建时的 `package.json`。检查按 SemVer 比较，普通提交、单独创建的 Git 标签、草稿和预发布版都不会触发更新通知。没有更新或网络异常时，书库照常打开。

在「设置」的「帮助与更新」中可手动检查、查看版本号和更新说明。发现新版时显示非弹窗提示，可在本次运行期间忽略同一版本；「查看更新」会直接打开设置中的更新说明。

- Windows 版从最近 100 条 GitHub Releases 中选取带 SHA-256 校验值的 Windows x64 正式安装包。点「更新并重启」后，应用内会显示下载进度。下载时可继续写作。安装包校验通过后，应用保存正文、关闭窗口并覆盖原安装目录，安装完成后自动启动。
- 如果正文保存失败，窗口会保留，保存或另存后可继续更新。v0.6.0 及更早版本需先手动覆盖安装一次 v0.7.0 或更新版本。
- Web 版查询 [GitHub Releases 最新正式发行版接口](https://api.github.com/repos/littleboylinlin/New_World/releases/latest)。站点已部署新版时，可选择「重新加载当前网页」，应用会先确认正文保存成功。本地运行时，请先更新代码并重启服务。

正常更新后，Windows 安装器移除旧程序文件；两端回收应用管理的更新下载缓存，并在新版界面正常打开后清理较早版本的语言包。版本变化时还会刷新旧的页面和编译缓存，不清除 IndexedDB 书库。Mac 也会清理默认下载目录中可识别的旧版中断下载文件。系统占用导致暂时无法删除的文件会重试，仍失败则保留到后续启动处理。书库、设置、当前版本语言包、手动保存的安装包及未知文件均保留。

检查只匿名获取公开版本元数据。小说、原文件和编辑稿均留在本机。

## 阅读和编辑

原创库的作品页可在**原文件**与各个**编辑版本**之间切换。可转换的原件用「转换为编辑稿」创建一份独立正文，PDF 使用「提取文字为编辑稿」。任何格式的作品都可以另建空白编辑稿。「另存为独立版本」可复制当前章节和正文，方便尝试另一种写法。

在续写／仿写库导入原作后，每部原作会有一个项目。项目的「续写列表」可以新建、打开独立续写稿，「原文列表」可以阅读、下载和补充同一原作的文件。需要时可从原文阅读页选择「以原文为底稿续写」。旧版已导入的原作及编辑稿会直接显示在对应列表，原先单独创建的稿件也可在其项目中添加原文。

- 章节目录支持新建、重命名、上下移动、切换和确认删除，并显示每章字数。正文上方显示本章和全书字数。本章标题可用于跳转，字数与文字处理软件的中文字数一致：每个汉字和中文标点算 1，英文等以空格分词的语言每个单词算 1，中英混排时分别计算后相加。
- 编辑器提供段落、标题、加粗、斜体、下划线、列表、引用、分隔线和本地插图。支持浏览器原生选区、剪贴板和中文输入法。
- `Ctrl / ⌘ + S` 保存，`Ctrl / ⌘ + F` 查找本章，`Ctrl / ⌘ + B/I/U` 切换行内样式，`Ctrl / ⌘ + Z` 撤销，`Ctrl / ⌘ + Shift + Z` 重做。查找按字面匹配，可逐处或全部替换。撤销记录属于当前章节编辑会话。
- 「阅读模式」保留目录与查找，编辑操作可通过「编辑正文」恢复。手机宽度下可展开章节目录，工具栏可横向滚动。
- 「专注写作」隐藏目录、页眉以外的按钮和页脚，只留本章正文，工具栏淡化、指向时再显示。按 `Esc` 或再点一次退出，离开页面时自动退出。
- 页面跳转、章节切换、弹窗和提示带有过渡动画。系统开启「减少动态效果」时不播放动画。

## 回收站

删除作品、续写项目的原文、编辑版本或章节时，内容会移入回收站。删除后页面底部的提示可以直接撤销。顶栏的「回收站」列出已删除的内容，可恢复到原来的位置或彻底删除，也可以一次清空。

- 回收站保留 30 天，到期的内容在下次打开应用时清理。回收站里的内容仍占用本地存储空间。
- 恢复章节时回到原来的顺序。恢复编辑版本遇到同名版本时，会在名称后加上「恢复」。
- 所属的作品或版本已删除时，需要先恢复它。删除后又导入了相同的原文件时，需要先删除新导入的那一份。

## 格式能力

「编辑」指原件可转换为独立编辑稿。「导出」指编辑稿可生成该格式的新文件。原件下载是独立操作，会保留导入时的文件名和字节。

导出时可以勾选章节并预览首个所选章节。PDF、DOCX 和 HTML 默认使用白底黑字的标准样式，也可以切换到紧凑或宽松。TXT 保留段落间距，Markdown 保留标题、列表等标记，两种格式都能预览文本。

| 格式 | 导入原件 | 原件预览 | 转换为编辑稿 | 导出编辑稿 | 已知限制 |
| --- | --- | --- | --- | --- | --- |
| TXT | 是 | 正文 | 是 | UTF-8 TXT | 可手动切换 UTF-8、GB18030／GBK、Big5、UTF-16 LE／BE 和 Windows-1252。长段落会分章，导出将富文本和图片简化为文字。 |
| Markdown | 是 | 源文 | 是 | Markdown | 保留常用标题、列表、引用和样式。导出时下划线、图片和复杂表格会简化。 |
| HTML | 是 | 正文文本 | 是 | 独立 HTML | 转换常用结构和内嵌光栅图，剔除脚本、网页样式和远程资源。 |
| RTF | 是 | 正文文本 | 部分 | — | 支持正文、Unicode 与常见 ANSI 编码、基础行内样式。图片、复杂列表和表格留在原件。 |
| DOCX | 是 | 正文文本 | 是 | DOCX | 常用文字样式、标题、列表、表格与可解码内嵌图。分页、脚注、页眉页脚、修订和复杂布局可能简化。 |
| DOC | 是 | — | — | — | 保存及下载旧版 Word 原件。 |
| ODT | 是 | 正文文本 | 部分 | — | 可提取标题、段落、基本列表、表格、常见样式与包内图。页式布局、重复单元格和复杂样式可能简化。 |
| EPUB | 是 | 按阅读顺序显示正文 | 部分 | — | 转换章节、常见样式和包内图。固定版式、外部资源和 DRM 内容留在原件。 |
| PDF | 是 | 逐页渲染 | 部分 | 桌面版直接保存 PDF，Web 通过打印另存 | 提取可读文字，顺序可能需要调整。扫描件需先做 OCR，加密件需先解锁。导出会重新分页。 |
| MOBI、AZW3 | 是 | — | — | — | 保存及下载电子书原件。 |

单文件导入上限 128 MiB，PDF 预览和转换上限 64 MiB，常规文本及压缩文档单个正文部件上限 16 MiB，RTF 上限 8 MiB。单张内嵌 PNG、JPEG、GIF 或 WebP 图片上限 4 MiB，转换的图片总量上限 24 MiB。转换过大的书籍或损坏、加密的文件时，应用会提示限制并保留原件。

## 保存与隐私

正文变更后约 700 毫秒自动保存，切换章节或返回书库前也会尝试保存。保存状态可见。空间不足时保留上次已提交内容和当前内存中的改动，支持重试或导出当前章节。不同页面同时改同一章会提示冲突，可另存为独立版本。浏览器或设备强制退出时，尚未提交的输入可能需要重新录入。

IndexedDB v3 在作品、文件、编辑版本和章节表旁新增回收站表。升级后的书库需要用 v0.5.0 或更新版本打开。两库按复合键隔离，原文件按库进行 SHA-256 去重。编辑稿和原件分别存取，删除作品时在同一事务中把本地副本、编辑版本和章节移入回收站。桌面版使用固定本机目录与应用地址，Web 数据按浏览器配置与网站地址隔离。清除浏览器站点数据会一并删除该浏览器的书库。

导入、转换、编辑和导出均在本地完成。插图保存在编辑稿中，HTML 导入及富文本粘贴会移除可执行内容与远程地址。

## 工程与验证

使用 Vite、TypeScript 和 Tiptap／ProseMirror。编辑器采用与源格式独立的结构化章节模型，格式转换、持久化和导出分别在 `src/documents/` 下维护。构建产物包含第三方许可证与归属文件。版本历史、AI 辅助和人物设定功能留待后续。

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

Playwright 使用生产构建，覆盖旧库迁移、格式转换与原件校验、章节管理、IME 组合输入、复制粘贴、保存失败、并发冲突、重开恢复和手机视口。CI 保存公开测试样本的截图及导出文件。已有 Chromium 可用 `CHROMIUM_PATH` 指定其可执行文件。

更新检查测试通过拦截 GitHub 接口注入可控的正式版、预发布版和故障响应。运行时读取实际 GitHub Releases 接口。

桌面版使用 Electron 打开相同的生产构建。在 Windows 运行 `npm run desktop` 可启动开发构建，`npm run build:windows` 生成 `dist-windows/` 内的 x64 NSIS 安装包。CI 在 Windows 运行实际安装包，验证离线读写、PDF 导出、应用内更新、原目录覆盖及重启后数据保留。Mac 使用 `npm run build:macos` 和 `npm run test:macos`，在 Apple Silicon 与 Intel 原生 runner 上从 DMG 安装并验证。

发布新版时，在 `release.json` 明确指定版本与 `windows`、`macos` 目标平台；Mac 专用发布不上传 Windows 安装包。在同一 PR 更新 `package.json` 与锁文件的版本，新增 `docs/releases/v<版本>.md`。合并到 `main` 后，CI 在 Web、Windows 和两种 Mac 芯片的检查均通过时生成正式 Release，上传安装包和 SHA-256 校验文件。也可以在 `main` 上手动运行 Checks，填写匹配的正式版本标签重试发布。发布前会校验产物清单，拒绝与目标平台不符的文件。

界面文案集中在 `locales/zh-CN.json` 和 `locales/en.json`。构建时检查两者的键与插值参数，并生成独立语言包和校验清单。桌面安装包包含校验清单，不包含语言包；Release 同时提供两个语言文件，安装器和应用只取得所选语言。修改文案后应更新两个源文件并随新版一起发布。
