# New World

New World v0.3.1 是一个本地小说管理器。原创库用于创作和管理自己的小说，续写／仿写库按原作组织续写项目。

## 运行

需要 Node.js 22.16 或更新版本。使用 Node.js 24 运行 CI。

```sh
npm ci
npm run dev
```

用浏览器打开终端显示的本机地址。`npm run build` 生成可通过 HTTPS 托管的静态站点，`npm run preview` 在本机运行生产构建。

## 版本更新

每次载入页面时，应用在后台向本仓库的 [GitHub Releases 最新正式发行版接口](https://api.github.com/repos/littleboylinlin/New_World/releases/latest) 检查一次。界面上的运行版本来自构建时的 `package.json`。检查按 SemVer 比较，普通提交、单独创建的 Git 标签、草稿和预发布版都不会触发更新通知。没有更新或网络异常时，书库照常打开。

在「帮助与更新」中可手动检查、查看版本号和更新说明。发现新版时显示非弹窗提示，可在本次页面载入期间忽略同一版本。发布页在新标签页打开。若站点已经部署新版，可以点「重新加载当前网页」，应用会先确认当前正文保存成功。本地运行时，更新代码并重启服务后再重新加载网页。

检查只匿名获取公开的版本元数据。小说、原文件和编辑稿保留在原有本地存储中。维护者发布新版时，请在 GitHub 创建与项目版本匹配的正式 Release 并填写说明。

## 阅读和编辑

原创库的作品页可在**原文件**与各个**编辑版本**之间切换。可转换的原件用「转换为编辑稿」创建一份独立正文，PDF 使用「提取文字为编辑稿」。任何格式的作品都可以另建空白编辑稿。「另存为独立版本」可复制当前章节和正文，方便尝试另一种写法。

在续写／仿写库导入原作后，每部原作会有一个项目。项目的「续写列表」可以新建、打开独立续写稿，「原文列表」可以阅读、下载和补充同一原作的文件。需要时可从原文阅读页选择「以原文为底稿续写」。旧版已导入的原作及编辑稿会直接显示在对应列表，原先单独创建的稿件也可在其项目中添加原文。

- 章节目录支持新建、重命名、上下移动、切换和确认删除。本章标题可用于跳转，字数按非空白 Unicode 字符计数。
- 编辑器提供段落、标题、加粗、斜体、下划线、列表、引用、分隔线和本地插图。支持浏览器原生选区、剪贴板和中文输入法。
- `Ctrl / ⌘ + S` 保存，`Ctrl / ⌘ + F` 查找本章，`Ctrl / ⌘ + B/I/U` 切换行内样式，`Ctrl / ⌘ + Z` 撤销，`Ctrl / ⌘ + Shift + Z` 重做。查找按字面匹配，可逐处或全部替换。撤销记录属于当前章节编辑会话。
- 「阅读模式」保留目录与查找，编辑操作可通过「编辑正文」恢复。手机宽度下可展开章节目录，工具栏可横向滚动。

## 格式能力

「编辑」指原件可转换为独立编辑稿。「导出」指编辑稿可生成该格式的新文件。原件下载是独立操作，会保留导入时的文件名和字节。

| 格式 | 导入原件 | 原件预览 | 转换为编辑稿 | 导出编辑稿 | 已知限制 |
| --- | --- | --- | --- | --- | --- |
| TXT | 是 | 正文 | 是 | UTF-8 TXT | 可手动切换 UTF-8、GB18030／GBK、Big5、UTF-16 LE／BE 和 Windows-1252。长段落会分章，导出将富文本和图片简化为文字。 |
| Markdown | 是 | 源文 | 是 | Markdown | 保留常用标题、列表、引用和样式。导出时下划线、图片和复杂表格会简化。 |
| HTML | 是 | 正文文本 | 是 | 独立 HTML | 转换常用结构和内嵌光栅图，剔除脚本、网页样式和远程资源。 |
| RTF | 是 | 正文文本 | 部分 | — | 支持正文、Unicode 与常见 ANSI 编码、基础行内样式。图片、复杂列表和表格留在原件。 |
| DOCX | 是 | 正文文本 | 是 | DOCX | 常用文字样式、标题、列表、表格与可解码内嵌图。分页、脚注、页眉页脚、修订和复杂布局可能简化。 |
| DOC | 是 | — | — | — | 保存及下载旧版 Word 原件。 |
| ODT | 是 | 正文文本 | 部分 | — | 可提取标题、段落、基本列表、表格、常见样式与包内图。页式布局、重复单元格和复杂样式可能简化。 |
| EPUB | 是 | 按阅读顺序显示正文 | 部分 | — | 转换章节、常见样式和包内图。固定版式、外部资源和 DRM 内容留在原件。 |
| PDF | 是 | 逐页渲染 | 部分 | 浏览器打印／另存 PDF | 提取可读文字，顺序可能需要调整。扫描件需先做 OCR，加密件需先解锁。PDF 输出由浏览器重新分页。 |
| MOBI、AZW3 | 是 | — | — | — | 保存及下载电子书原件。 |

单文件导入上限 128 MiB，PDF 预览和转换上限 64 MiB，常规文本及压缩文档单个正文部件上限 16 MiB，RTF 上限 8 MiB。单张内嵌 PNG、JPEG、GIF 或 WebP 图片上限 4 MiB，转换的图片总量上限 24 MiB。转换过大的书籍或损坏、加密的文件时，应用会提示限制并保留原件。

## 保存与隐私

正文变更后约 700 毫秒自动保存，切换章节或返回书库前也会尝试保存。保存状态可见。空间不足时保留上次已提交内容和当前内存中的改动，支持重试或导出当前章节。不同页面同时改同一章会提示冲突，可另存为独立版本。浏览器或设备强制退出时，尚未提交的输入可能需要重新录入。

IndexedDB v2 在原有作品和文件表旁新增编辑版本和章节表。两库按复合键隔离，原文件按库进行 SHA-256 去重。编辑稿和原件分别存取，删除作品时在同一事务中清理其本地副本与章节。数据按浏览器配置与网站地址隔离。清除站点数据会一并删除书库。

导入、转换、编辑和导出均在本地完成。插图保存在编辑稿中，HTML 导入及富文本粘贴会移除可执行内容与远程地址。

## 工程与验证

使用 Vite、TypeScript 和 Tiptap／ProseMirror。编辑器采用与源格式独立的结构化章节模型，格式转换、持久化和导出分别在 `src/documents/` 下维护。构建产物包含第三方许可证与归属文件。版本历史、AI 辅助和人物设定功能留待后续。

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

Playwright 使用生产构建，覆盖旧库迁移、格式转换与原件校验、章节管理、IME 组合输入、复制粘贴、保存失败、并发冲突、重开恢复和手机视口。CI 保存公开测试样本的截图及导出文件。已有 Chromium 可用 `CHROMIUM_PATH` 指定其可执行文件。

更新检查测试通过拦截 GitHub 接口注入可控的正式版、预发布版和故障响应。用例在真实浏览器中验证请求、提示、手动重试和保存检查，运行时读取实际 GitHub Releases 接口。
